# Doug Miller’s writing samples

This folder provides a selection of my writing samples. It includes:
- **Corero_Management_Server_help**: Open **Default.htm** to browse this help system that I authored using MadCap Flare to describe Corero Network Security's DDos mitigation solution.
- **Resume**: A PDF of my current resume, originally authored in Markdown and exported to PDF.
- **RiverbedTech_samples**:
    - RiverbedAppResponse_SecurityOverview: This PDF is a general introduction to security considerations for the Riverbed AppResponse packet inspection system. This was authored using Adobe FrameMaker.
    - RiverbedIQ_topic_samples: These are PDFs of selected topics from Riverbed IQ's embedded application help ("user assistance"), all of which I authored in MadCap Flare. Riverbed IQ is a web-based SaaS product with its help system built in to the application, so I do not have a standalone help system for it the way that I do for the Corero Management Server. The file named **RiverbedIQ_UA_complete.pdf** comprises the entire help system organized as a sequential document.
    - RiverbedIQ_Videos: This includes several videos that I wrote and recorded to illustrate different aspects of Riverbed IQ. These videos were linked directly from the application and were included in the help system.
