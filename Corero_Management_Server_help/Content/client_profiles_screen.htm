Client Profiles screen

Click Manage Profiles in the Client Groups screen to display the Client Profiles screen. Client profiles define sets of characteristics that constitute acceptable traffic behavior from clients; this includes SYN floods, connection limits, and packet rate limits. Each is a separate type of profile which can be assigned independently to client groups. Each of these is configured in its own screen, which is nested in this Client Profiles screen.

For each profile type, click Add to display the corresponding screen and begin creating a new one, or click the name of an existing profile to modify it.

All of these controls are available also through the corresponding CLI commands, as noted in each section below.

SYN Flood Profile

A SYN flood profile enables you to define a set of thresholds for identifying and responding to excessive numbers of SYN packets. There are two built-in SYN flood profiles: megaproxy-client-behavior and normal-client-behavior.

You can access these controls also through the CLI command set defense profiles client-profiles syn-flood-profile.

  • Name Type a descriptive name for the profile.
  • Trusted Threshold – The number of successful and well-executed connections required to establish this IP address as a trusted IP address. Requests from trusted clients are forwarded to the destination address. The default is 5.
  • Suspicious Threshold – The source IP address has reached a user specified threshold (Suspicious Threshold) due to the number of open SYNs. The device will proxy all connection requests to any device from that source IP address. The default is 5.
  • Suspicious Exit Threshold – The device maintains a count of the number of incomplete TCP connections destined to a server group and allows the user to set a value for this threshold (known as the Connection Threshold). When a source Client Group is in the Unknown or Trusted states, and the destination's Server Connection Threshold has not been reached, then SYN packets received from this source to the given destination are passed directly on to the server group (subject to other security policy checks). The default is 45.
  • Malicious Threshold – The default is 100. The source IP address has reached an even higher user-specified threshold (Malicious Threshold) because of the number of open SYNs. The appliance blocks any connection request from this address until one of two things happens:

    • The address stops initiating requests for a given period of time called the timeout period.

    • The number of new, open SYNs drops enough over time (due to a decay mechanism) to allow the total open SYNs to decay to the suspicious level.

    If this limit is exceeded, the following rule is triggered and the action as defined for this rule is followed: cns-001007 'Connection From Malicious Source IP Address'

  • Proxy Requests From Unknown IP – This is unselected by default. Used for TCP connection traffic patterns for this address that are not yet identified. For IP addresses with an unknown threat level, you can configure the device to either:

    • Forward connection requests from this address to the destination device.

    • Proxy connection requests until the IP address becomes trusted.

Connection Limit Profile

Specify a maximum number of group connections (the default is 1048575) and a maximum number of member connections (the default is 32767). There are four built-in connection limit profiles: low-limits, normal-limits, very-high-limits, and virtual-server-limits.

You can access these controls also through the CLI command set defense profiles client-profiles connection-limit-profile.

Packet Rate Limit Profile

Specify the packet rate limit for this client. There are two built-in packet rate limit profiles: 20000-per-minute and request-limiting-disabled.

You can access these controls also through the CLI command set defense profiles client-profiles packet-rate-limit-profile.
