DNS Flood Attack

Definition

This attack directs a massive number of DNS requests at a DNS server in an effort to consume its processing power or memory. Typically, the attacking packets are directed at port 53 on the target, the well-known UDP port usually associated with DNS. This attack should not be confused with the DNS amplification attack, which uses a comparatively small number of initiating packets with spoofed IP addresses to generate a massive amount of bandwidth-consuming traffic.Rather, this attack seeks to exhaust memory or processing power. These attacks may leverage the resources of service providers, especially those that don't place a lot of emphasis on the security of their outbound traffic, rather than their inbound traffic.

Observable characteristics

An excessively large number of open SYN requests.

Method of response

Drop the first SYN packet from an unknown host during a DDoS attack.

CMS configuration steps

None. SYN flood protection is enabled by default.

This rule pertains to this attack type:
