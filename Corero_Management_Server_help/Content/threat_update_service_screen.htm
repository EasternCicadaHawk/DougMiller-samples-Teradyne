Threat Update screen

The Threat Update screen enables you to configure the means by which the CMS will obtain updates to its threat definitions via Protection Packs and Intelligence Packs. You must have a valid Threat Update Service license to be able to obtain these updates.

Click Defense Configuration > Threat Update Service in the web UI tool bar to display the Threat Update screen. Access the same functionality in the CLI with the set threat-update command.

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

The Threat Update screen provides these controls:

  • License Key – Type your Threat Update Service license key. The CLI equivalent for this is set threat-update license-key.
  • Threat Update Server Address – This is set explicitly to "tus.corero-cns.com", and cannot be modified.
  • Threat Update Schedule – Click this link to display the Threat Update Schedule screen for specifying the frequency with which the CMS will seek Threat Update Service updates from the server and push them to managed Defense appliances. You can choose to query and push updates every hour (the default), every day at a certain time, or at some custom interval. The CLI equivalent for this is set threat-update threat-update-schedule.
  • License Information – This section displays information about the Threat Update Service license associated with your license key. This includes the license's expiration date, current status, and the number of days remaining until it expires.
