LAND Attack

Definition

LAND is an acronym for "local area network denial." In this attack, the attacker sends packets to the target that have that target's IP address and port specified as both the source address and the destination address, causing the target to respond to itself endlessly. The attack sends these packets in large volume, resulting in denial of service to legitimate users.

Observable characteristics

cns-003002 triggers, indicating the arrival at the interface of packets bearing the same destination address as their source address.

Method of response

Block any and all incoming packets bearing the same destination address as their source address.

CMS configuration steps

None. cns-003002 is enabled by default.

Relevant SmartWall rules

This rule pertains to this attack type:

  • cns-003002: IP frame destination address equals source addr-LanD
