Top Service Flood Signature Type

Every 60 seconds the CMS creates a message that contains the most frequently signatures for potential service protocol flood attacks over the time period as determined by each Network Threat Defense appliance inbound from the Internet into the site.   There will be up to 10 entries in each message and each one contains the signature and its rates. The following is an example how this message is sent to configured syslog receivers and a description of the contents.

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=network, type=top-refl-rate,v=1,cl=Eur1,Eur1_1,aname=Defense_12_12_12_1, sig1="dip=172.16.1.104,prot=6,dprt=80,plen=63,ttl=64,flags=SYN", br1=34483948,pr1=393494, sig2="dip=172.16.1.103,prot=6,dprt=80,plen=63,ttl=64,flags=SYN:ACK",br2=2460055,pr2=40806

Mar =6,port1=41520,pcent2=64009,pcent2=17,port3=0,pcent3=17,
