System State Change Type

When certain significant system or network events occur, the CMS will issue a message indicating this change of state.  The following is an example how this report is sent to configured syslog receivers and a description of the contents.

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=system,type=state-change, v=1,cl=NYC1,pg=NYC1_1, aname=Defense_12_12_12_1,state-name=bypass-mode,old- state=inline, new-state=bypass

Example State Change Message

The specific content for the system state change message is:
