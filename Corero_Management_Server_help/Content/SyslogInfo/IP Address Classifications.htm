IP Address Classifications Type

Every 60 seconds the CMS creates a report that summarizes the classification of the IP addresses known across the Defense appliances. The following is an example how this report is sent to configured syslog receivers and a description of the contents.

Apr 6 12:56:34 12.12.12.5 Apr 6 08:58:03 server35-cms cat=security,type=ip-class, v=1,cl=all,pg=all,iua=6230138,iuta=56577,iusa=885,iuma=48,iuua=6172628,
