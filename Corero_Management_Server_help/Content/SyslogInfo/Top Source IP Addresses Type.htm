Top Source IP Addresses Type

Every 60 seconds the CMS creates a message that contains the most frequently seen source IP addresses over the time period as determined by sflow sampling of the data inbound from the Internet into the site.   There will be up to 10 entries in each message and each one contains the IP address and its percent of the samples. The following is an example how this message is sent to configured syslog receivers and a description of the contents.

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=network,type=top-sip, v=1,cl=all,pg=all,samples=6,ip1=208.87.136.155,pcent1=67,ip2=98.229.163.222,pcent2=17, ip3=66.203.81.178,pcent3=17,
