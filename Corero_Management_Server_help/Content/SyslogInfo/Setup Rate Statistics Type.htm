Setup Rate Statistics Type

Every 60 seconds the CMS creates a report that summarizes setup rate statistics for flows on the Defense appliances. The following is an example how this report is sent to configured syslog receivers and a description of the contents.

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=network,type=setups, v=1,cl=all,pg=all,tsr=134343,ntsr=74342,usr=73432,isr=32220,oisr=42420,

Example Setup Rate Statistics Message
