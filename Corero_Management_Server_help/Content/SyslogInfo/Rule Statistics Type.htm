Rule Statistics Type

Every 60 seconds the CMS creates one message for each active security rule in the system that contains the counts of the number of packets blocked or just detected and the number of security events issued for these two situations for that rule. The following is an example how this report is sent to configured syslog receivers and a description of the contents.

Apr 6 12:56:34 12.12.12.5 Apr 6 08:58:03 cat=security,type=rule-stats,v=1,cl=all,pg=all, name=cns-001005,rule=cns-001005, desc=PVNET: Connection containing UDP port zero, bec=1819,bpc=1819,dec=0,dpc=0,bpr=34,dpr=0,
