Common Types and Formats

All messages and values within the security data content of a syslog message have consistent formatting across similar information content and information structure (e.g. the representation of tabular information). By understanding some of the common representations as they are made visible in the receiving tools, most of the messages are relatively self-describing. This section provides a description of these common representations.

name = value

All data is represented as a sequence of name=value pairs, possibly within a JSON table representation based on the data.  name is a short name optimized for syslog transmission and SIEM query construction, with consideration for ease of understanding from the full field name. value is the value of the named data.  If names consist of more than one word, they are separated by a “-“ (dash). There are no spaces in name=value.

Field separators

All fields (name=value) are separated by commas. There are no spaces before or after the comma.
