Top Security Rules Type

Every 60 seconds the CMS creates a report that contains the security rules that had the highest blocked packet rates over the time period. There will be up to 10 entries in each message and each one contains the rule that fired and the percentage of the samples. The following is an example how this report is sent to configured syslog receivers and a description of the contents.

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=security, type=top-rules, v=1,cl=all,pg=all,rule1=cns-100027,pcent1=93,rule2=cns-001025,pcent2=4,rule3=cns-001017, pcent3=2,
