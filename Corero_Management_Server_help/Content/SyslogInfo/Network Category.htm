Network Category

Interface Statistics Type

Every 60 seconds the CMS creates a report that summarizes interface statistics for the external (from the Internet) and internal (toward the firewall and servers) ports of the protection groups on the Defense appliances. The following is an example how this report is sent to configured syslog receivers and a description of the contents.

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=network,type=interface, v=1,cl=all,pg=all,eprp=230922943,eptp=181472787,eprb=207772986979,eptb=61164066743,epbrr=4,epprr=670,epptr=443,epbtr=0,ipptr=670,ipbtr=4,ipprr=443,ipbrr=0,iprp=181473093,iptp=230922664, iprb=61164161900,iptb=207772844918,
