Top Server Groups Type

Every 60 seconds the CMS creates a message that contains the most frequently seen destination server groups over the time period as determined by sflow sampling of the data inbound from the Internet into the site.   Server groups are configured in the CMS in the context of server protection instances. This configuration includes lists of IP addresses, ranges, and networks that are to receive the specific protection defined in that configuration.   This statistic aggregates the destination IP addresses of the sampled packets into the configured server groups and determines the rank ordering of these server groups for each time period.

There will be up to 10 entries in each message and each one contains the group name and its percent of the samples. The following is an example how this message is sent to configured syslog receivers and a description of the contents.

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=network,type=top-srvgrp, v=1,cl=all,pg=all,samples=60977656,group1=Web_Servers,pcent1=67,group2=DNS_Servers,pcent2=17, group3=default,pcent3=17,
