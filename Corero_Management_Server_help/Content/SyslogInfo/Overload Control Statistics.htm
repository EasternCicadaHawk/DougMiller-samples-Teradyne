Overload Control Statistics Type

Every 60 seconds the CMS creates a report that summarizes overload control statistics for packet processing on the Defense appliances. The following is an example how this report is sent to configured syslog receivers and a description of the contents.

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=network,type=overload, v=1,cl=all,pg=all,iod=0,iodr=0,eop=134343,eopr=743,

Example Overload Control Statistics Message
