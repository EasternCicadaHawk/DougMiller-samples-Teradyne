Protection Group Status Type

Every 60 seconds the CMS creates a report that summarizes the status of each protection group.  The following is an example how this report is sent to configured syslog receivers and a description of the contents.

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=system,type=pg-status, v=1,cl=NYC1,pg=NYC1_1,devices=3,reachable=3,in-sync=3,defense-mode=mitigate,bypass-mode=inline,min-uptime=234343,

Example Protection Group Summary Status Message

The specific content for the protection group summary status message is:

 

Field Name

Short Name

Specific Value / Type

Description

Cat

cat

system

System event category

Type

type

pg-status

Protection Group summary status

Version

v

Number

The Corero message format version

Cluster

cl

Text

The cluster of the protection group

Protection Group

pg

Text

The protection group of this status

Number of devices

devices

Number

The number of devices configured in the protection group

Number of Reachable Devices

reachable

Number

The number of devices that are reachable in the protection group

Number of In-Sync Devices

in-sync

Number

The number of devices with in-sync deployment state in the protection group

Defense Mode Summary Status

defense-mode

Text [mitigate,

          monitor,

          bypass,

          not-applicable,

          not-in-sync]

The defense mode of the protection group if there is at least one Defense appliance, otherwise not applicable.  If an appliance is not in sync, the summary status is not-in-sync

Bypass Mode Summary Status

bypass-mode

Text [inline,

          monitor,

          bypass,

          not-applicable]

The bypass mode of the protection group if there is a Bypass appliance in the configuration, otherwise not-applicable

Minimum Uptime

min-uptime

Number

The minimum uptime in seconds of all of the devices in the protection group.
