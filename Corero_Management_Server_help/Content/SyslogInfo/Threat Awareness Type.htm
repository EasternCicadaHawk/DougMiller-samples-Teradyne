Threat Awareness Type

Every 60 seconds the CMS creates a report that summarizes threat awareness status for a set of significant internal indicators across the Defense appliances. The following is an example how this report is sent to configured syslog receivers and a description of the contents.

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=security,type=threats, v=1,cl=all,pg=all,epfbc=0,enia=0,eatu=0,entsr=0,etsr=0,
