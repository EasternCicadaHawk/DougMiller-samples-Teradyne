Sflow Event Type

Each Network Threat Defense appliance samples the data stream and sends the samples to the CMS for threat and operational analysis.   A subset of these events are sampled as well and sent as syslog messages for further integration in the SIEM analysis stream. Five messages per second are forwarded as syslog events.
