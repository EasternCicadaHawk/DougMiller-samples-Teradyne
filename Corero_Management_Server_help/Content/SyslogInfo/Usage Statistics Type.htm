Usage Statistics Type

Every 60 seconds the CMS creates a report that summarizes usage statistics on the Defense appliances. The following is an example how this report is sent to configured syslog receivers and a description of the contents.

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=network,type=usage, v=1,cl=all,pg=all,iuf=503343,iutf=352434,iuuf=1055656,iuif=34342, iuof=14566,tps=34340, tpf=120,
