Alarm Type

The CMS generates alarms for significant system events. A single type of syslog message carries the information for each alarm. These alarms have fields that can be broken out and indexed, and they also carry the full text.

Some of the types of alarms currently supported in the CMS are:

  • Connection failure to an appliance
  • Appliance has rebooted
  • Interface has gone down

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=system,type=alarm, v=1, aname=Defense_10_20_27_111,v=1,atype=al:connection-failure,sev=MAJOR,clrd=true,sp=none, txt=Failed to connect to device Defense_10_20_27_111: connection refused: Device not responding
