Device Status Type

Every 60 seconds the CMS creates a report that summarizes the status of each device in the system.  The following is an example how this report is sent to configured syslog receivers and a description of the contents.

Mar 16 11:00:58 10.20.29.52 Mar 16 11:04:46 corpit-cms.corero.com cat=system,type=device-status, v=1,cl=NYC1,pg=NYC1_1,aname=Defense_12_12_12_1,ver=V8.05.109,uptime=298848,deployment-state=in-sync,defense-mode=mitigate,bypass-mode=not-applicable,forensics-mode=not-applicable

Example Device Status Message

The specific content for the device status message is:

 

Field Name

Short Name

Specific Value / Type

Description

Cat

cat

system

System event category

Type

type

device-status

Specific status of this device/appliance

Version

v

Number

The Corero message format version

Cluster

cl

Text

The cluster of the protection group

Protection Group

pg

Text

The protection group of this status

Device/Appliance Name

aname

Text

The name provisioned for this device (appliance)

Software Version

ver

Text

The current software version in operation on this device

Uptime

uptime

Number

The number of seconds since this device has been rebooted

Configuration Deployment State

Deployment-state

Text  [in-sync,

           not-in-sync]

The configuration sync status between the CMS and the device

Defense Mode of Device

defense-mode

Text [mitigate,

          monitor,

          bypass,

          not-applicable,

          not-in-sync]

The defense mode of the device if it is a Network Threat Defense appliance and the deployment mode is in-sync.  Otherwise, the values are not-applicable and not-in-sync, respectively

Bypass Mode of Device

bypass-mode

Text [inline,

          monitor,

          bypass,

          not-applicable]

The bypass mode of the device if it is is a Network Bypass appliance and the deployment mode is in-sync.  Otherwise, the values are not-applicable and not-in-sync, respectively

Forensics Mode of Device

forensics-mode

Text [inline,

          monitor,

          bypass,

          not-applicable]

The forensics mode of the device if it is a Network Forensics appliance and the deployment mode is in-sync.  Otherwise, the values are not-applicable and not-in-sync, respectively
