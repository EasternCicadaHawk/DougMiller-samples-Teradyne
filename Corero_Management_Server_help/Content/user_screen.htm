User screen

Click an existing user account to modify it, or click Add in the Users screen to display the User screen and begin defining a new user.

Refer to AAA (Authentication, Authorization, and Accounting) Overview for a general description of the CMS's user account management.

The User screen provides these controls, which are available also through the CLI command set aaa authentication users user username:

  • UID – The numerical user ID value associated with this account.
  • GID – The numerical group ID value associated with this account.
  • Password – The password string for the account. This is displayed as a hashed value, but you can type a new password in clear text.
  • SSH Keydir – The path to where this account's SSH key resides, if SSH is used during the authentication process.
  • Homedir – The absolute path to this account's home directory.
