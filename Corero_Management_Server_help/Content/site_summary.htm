Status screen [Defense Monitoring]

The Status screen summarizes the current behavior of the site's Defense, Bypass, and Forensics appliances, as well as very high-level summaries of excessive activity counts that may indicate an attack on your servers.

Click Defense Monitoring > General Status in the web UI tool bar to display the Status screen, or type the CLI command show defense status to display the same information.

Summary

  • Defense State – The default value is Normal.
  • Bypass State – The default value is Normal.
  • Forensics State – The default value is Normal.

Threat Awareness

  • Excessive Packets From Bad Hosts – The default value is False.
  • Excessive Proxy Setup Rate – The default value is False.
  • Excessive New IP Addresses – The default value is False.
  • Excessive Non-TCP Setup Rate – The default value is False.
  • Excessive Failed Proxy Rate – The default value is False.
  • Excessive TCP Setup Rate – The default value is False.
