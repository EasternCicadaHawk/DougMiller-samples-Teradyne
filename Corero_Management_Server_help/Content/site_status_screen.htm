Status screen [Site Configuration]

Clicking Site Configuration > General Status in the web UI tool bar displays a Status screen .providing an overview of software version usage, CPU utilization, and maximum temperature across the site. The same information can be accessed using the CLI command show site status.

The following information is available:

  • Summary Status – Normal.
  • Min Software Version – Software loaded on an appliance in the site.
  • Max Software Version – Software loaded on an appliance in the site.
