Backing Up and Restoring a CMS Configuration

Clicking CMS > CMS Backup/Restore in the web UI tool bar displays the CMS Backup/Restore screen, providing controls for saving and reloading the CMS configuration. Configuration backups (backup bundles) are created for a specific CMS version.

Note: No more than one backup is retained on the CMS file system(s) at any one time.

Action Where to perform it What to do
Back up the current CMS configuration. Web UI: Click CMS > CMS Backup/Restore in the web UI tool bar.

CLI: request backup create file filename

 Click Create Backup to execute the backup operation. The web UI will prompt you for confirmation that you really want to back up the configuration.
Restore the backed up CMS configuration. Web UI: Click CMS > CMS Backup/Restore in the web UI tool bar.

CLI: request backup restore file filename

Click Restore Backup to execute the restore operation. The web UI will prompt you for confirmation that you really want to restore the configuration.

NOTE: The CMS will restart as soon as the restoration is complete.
Save your changes when you're finished. Web UI: Save CLI: commit
