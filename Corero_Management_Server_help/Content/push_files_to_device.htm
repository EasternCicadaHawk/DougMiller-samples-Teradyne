Push Images To Device screen

Clicking Site Configuration > Push Images To Device in the web UI tool bar displays the Push Images To Device screen. This screen enables you to distribute a variety of different image file types to the appliances in your site, including software upgrades.

This screen enables you to upgrade the software on any Corero appliance:

  • SmartWall Network Threat Defense Appliance
  • SmartWall Network Bypass Appliance
  • SmartWall Network Forensics Appliance

NOTE: Make sure to Save your configuration after using this screen to make any changes to ensure that information about those changes is retained properly. For example, if you upload a file to the CMS for distribution to Corero appliances, but exit the CMS before saving the configuration change, the file will be present in the directory to which it was uploaded, but will not be shown in CMS configuration.

The following information is shown for each image file, regardless of its type:

  • Name
  • URL
  • Date
  • Status

The following controls are provided for handling the images:

  • Add button – Display the Upload dialog to acquire a file that can be distributed to one or more appliances.
    In the current release, you need to browse for the image in your local file system, rather than specifying its URL.
  • Delete button – Select a file to remove it from the configuration and the directory in which it is stored.
  • Push selected file to – Indicate whether the selected file will be pushed to every appliance in the site or to a single specific appliance only. Activate this button by selecting an image in the list.
  • Push File button – Click this to execute the transfer of the selected file to the specified appliances. Activate this button by selecting an image in the list.

Upon being pushed to an appliance, the image is transferred, and it takes some time until it runs actively on the appliance. Go to the Device Status screen to verify that the applaince is back up and running the expected version of software.
