Bypass Appliance Best Practices

This topic summarizes some best practices to employ and some ideas to consider when using a SmartWall Network Bypass Appliance in your site.

Modes of operation:

  • Bypass mode: Bypass mode provides connectivity protection to your site in the event of a power outage, or the need to perform maintenance or experiments on other SmartWall appliances. Traffic passes through the Bypass appliance directly from one network port to the other, without being passed to attached appliances, or being handled or treated in any other way.
  • Inline mode: Traffic is bridged between the Bypass appliance's inbound network port and its inbound inspection port. The traffic is handed off to the attached Corero appliances, and, once their handling of the traffic is complete, the treated traffic re-enters the bypass appliance at its outbound inspection port, where it is bridged to the outbound network port for being passed to the server infrastructure.
  • Monitor mode: Traffic passes straight through the Bypass appliance, but is copied also to the inbound inspection port so that it can be handled by attached Corero appliances. The Bypass appliance drops the treated traffic at its outbound network port, preventing the treated traffic from entering the network. This mode is useful for non-intrusive evaluation and experiments for which you want to have visibility into the behavior of the SmartWall Threat Defense System without allowing the treated traffic into your network.

You can upgrade the software for any Corero appliance in any of these modes.

The optical bypass mode should used solely in the event of a power failure. It is possible to test the optical bypass mode by setting the Optical Bypass option in the Cluster Configuration screen's Bypass Mode menu, but this option should not be used for any purpose other than verifying that the optical bypass mode works as it should.

After a power failure has occurred and power has been restored, the Bypass appliance will come back up in Bypass mode (switched bypass, not optical bypass). You will need to change the mode explicitly to Inline or Monitor once you have determined that the rest of your network has recovered properly.
