Data Models

A data model describes how data is represented and accessed in the CMS, providing a structured summary of the elements that need to be specified to configure a functional component. This section describes the data models that are exposed through the CMS, enabling you to configure appliance behavior.

The CMS manages five basic sets of entities for a site:

  • Administration – Administrative information for accessing and using the CMS.
  • AAA – Authentication, authorization, and accounting configuration for the CMS itself.
  • Devices – The appliances that are managed by this CMS.
  • Protection – The set of profiles, server protection, and immediate practices that protect your servers and other critical resources inside your organization's firewall.
  • Rules – Definitions of how traffic should be handled when it matches certain criteria. Rules are built-in to the CMS software, but can be combined together into user-defined rule sets.
