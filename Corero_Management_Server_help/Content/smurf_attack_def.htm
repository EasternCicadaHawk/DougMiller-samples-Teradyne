Smurf Attack

Definition

A Smurf attack is a variant of ICMP flood attack that uses the technique of amplification. Unlike a traditional ICMP flood attack, which simply bombards its target directly with ICMP packets, a Smurf attack broadcasts a very large number of ICMP requests to an available network. The source address of those ICMP packets, though, has been prepared (spoofed) with the IP address of the intended target. When the hosts to which the requests have been broadcast respond to those ICMP requests, they respond to the source IP address contained in the packet, which is that of the target. Subsequently, the target is inundated with ICMP responses, consuming its bandwidth and making it unavailable to legitimate users.

Observable characteristics

ICMP requests sent to a broadcast/multicast address.

Method of response

Block ICMP requests sent to a broadcast/multicast address.

CMS configuration steps

None. Rule cns-003015 is enabled by default.

Relevant SmartWall rules

This rule pertains to this attack type:

  • cns-003015: UDP echo has multicast destination IP - Fraggle
