Configuration Actions screen

Click Site Configuration > Configuration Actions in the web UI tool bar to display the Configuration Actions screen. This screen provides controls for coordinating the transfer of the site configuration between the CMS and the managed devices.

The Configuration Actions screen provides these controls:

  • Sync All Devices – For all devices in the site, default the configuration on each appliance and push the new configuration from the CMS.
  • Deploy – Push recent configuration changes to the site's devices. This is the same as using the CLI command request config deploy.
  • Force Sync – For an individual device, default its configuration and push the new configuration from the CMS.
  • Reset Configuration – For a selected appliance, choose. Reset Policy Configuration or Reset All Configuration.
  • Restart Device – For a selected appliance, choose Application Only, Operating System, or Hardware to indicate the level at which you want to restart the appliance.

The Deploy and Force Sync commands may be necessary when appliances are down at the time the configuration is saved, or when new appliances are added to a running site. If there is a need to perform one of these actions, the Sync Status icon below the CMS menu bar will be lit. Unless the Sync Status icon is lit and indicates that a Deploy or Force Sync action is necessary, you should use the Save command as the primary mechanism for pushing a configuration to appliances.
