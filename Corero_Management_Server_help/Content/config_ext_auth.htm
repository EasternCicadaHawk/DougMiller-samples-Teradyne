Configuring an External Authentication Regime

To access the controls for configuring an external authentication regime, click CMS > Users in the web UI tool bar to display the Users screen, then click External Authentication to display the External Authentication screen. The same functionality is accessible in the CLI by using the set aaa external-authentication command in configuration mode.

Configure an external authentication regime:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do
Specify the authentication regime to use. Web UI: In the Authentication Type section, choose Active Directory or RADIUS from the pulldown menu.

CLI: set aaa external-authentication [active-directory | radius]

 If you specified Active Directory, there is no additional configuration.

If you specified RADIUS, type the shared secret to use.
Specify the authentication server to use. Web UI: In the Server section,type the server name and .choose its administrative state, Enabled or Disabled.

CLI: set aaa external-authentication server servername admin-state [enabled | disabled]

 Specify the DNS name or IP address of the server and its administrative state.
Map external user groups to as CMS user groups as necessary. Web UI: Use the Group Mapping section and the Reject If No Group option.

CLI: set aaa external-authentication reject-if-no-group [false | true]

set aaa external-authentication group-mapping [admin | defense | monitor | no-access | support] externalgroupname

 Select Reject If No Group if you want to deny all access to users if their profile does not belong to one of the groups mapped here. This is selected by default.

Specify group name equivalents.
