Showing Appliance Status

You can display important information about the overall state of an appliance in the site. This includes:

  • deployment state
  • software version
  • sync reason
  • uptime
  • defense mode
  • bypass mode
  • forensics mode

Do this by typing this command, where appliancename is the configured name of the appliance in the site:

curl -k -v -u admin:admin https://cmsipaddress/api/operational/devices/device/appliancename/operations --header "Accept: application/vnd.yang.data+json"
