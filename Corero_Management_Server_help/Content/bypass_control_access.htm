Accessing Bypass Mode and Defense Mode Controls

Controls for configuring Bypass mode and Defense mode reside in different places for different contexts. Individual clusters can have their Bypass mode and Defense mode configured independently of the Global Bypass mode and Global Defense mode that are configured as the default behavior for the entire site.

Remember that Bypass mode is available only when a Bypass appliance is in use.

Global Bypass mode configures the default Bypass behavior for the entire site. Global Bypass mode supersedes Global Defense mode; if Global Bypass mode is set to Bypass, it doesn't matter how Global Defense mode is configured, because the attached Defense appliances won't receive any traffic. If Global Bypass mode is set to Inline or Monitor, then Defense and Forensics appliances will still receive packets and handle them as they are configured to do so.

Bypass mode/Defense mode can be configured in the following contexts:

  • To configure the default Bypass mode for the entire site: Choose Site Configuration > Cluster Configuration from the web UI tool bar and choose the desired option from the Global Bypass menu. The CLI equivalent is set site topology-settings global-bypass-mode.
    For the REST API,     type: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/site/topology-settings -d '{"global-bypass-mode": "bypassmode" }' --header "Content-Type:application/vnd.yang.data+json"
  • To configure the default Defense mode for the entire site: Choose Defense Configuration > Operations Settings from the web UI tool bar, and choose the desired option from the Global Defense Mode menu. The CLI equivalent is set defense operations-settings global-defense-mode.
    For the REST API,     type: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/defense/operations-settings -d '{"global-defense-mode": "defensemode" }' --header "Content-Type:application/vnd.yang.data+json"
  • To configure the Bypass mode for a specific cluster: Choose Site Configuration > Cluster Configuration from the web UI tool bar and select the cluster for which you want to configure the Bypass mode. Choose the desired option from the Bypass menu in the Edit Protection Group section of the screen. The CLI equivalent is set site topology-settings cluster clustername protection-group protectiongroupname bypass-mode.
    For the REST API,     type: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/site/topology-settings/cluster/clustername/protection-group/protectiongroupname -d '{"bypass-mode": "bypassmode" }' --header "Content-Type:application/vnd.yang.data+json"
