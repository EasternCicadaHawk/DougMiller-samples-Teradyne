IP Address Spoofing

IP address spoofing is the technique of falsifying a packet's source IP address. This practice is useful first because it helps to conceal the origin of an attack by making it appear as though the packets are sent from one or more different hosts than they really are. Secondly, and possibly more importantly,spoofing can be used in reflection attacks and amplification attacks to make that falsified source address the target of attack traffic. Spoofing is used also in SYN flood attacks as a means of ensuring that connection requests are not completed.
