Packet-Based Rules screen

Click Defense Configuration > Packet-Based Rules in the web UI tool bar to display the Packet-Based Rules screen, or use the CLI command set defense profiles rule-groups packet-rules to access the same functionality.

This screen provides a catalog of all the packet-based rules used in the SmartWall Threat Defense System, displaying a summary of basic information for each, including its Admin State, Action, whether it is logged or not, its Severity, and short and long descriptions of the rule. Clicking a rule number displays a screen that enables you to customize the rule's configuration.
