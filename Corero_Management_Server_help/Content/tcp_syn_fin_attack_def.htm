TCP SYN+FIN Attack

Definition

This attack involves sending a TCP packet that has both the SYN flag and the FIN flag set. Though the response can vary somewhat, the target typically responds to both flags, first acknowledging the SYN and transitioning to SYN_RCVD, then acknowledging the FIN, and transitioning to CLOSE_WAIT, where it stays stuck until the keep-alive value expires. Multiplied by a large number of such malicious packets, this results in an inability to respond to legitimate traffic, and a corresponding denial of service.
