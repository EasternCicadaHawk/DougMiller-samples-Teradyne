Threat Update Schedule screen

Clicking the Threat UpdateSchedule link in the Threat Update Service screen displays the Threat Update Schedule screen for specifying the frequency with which the CMS will seek Threat Update Service updates from the server and push them to managed Defense appliances. The CLI equivalent for this is set threat-update threat-update-schedule.

The Threat Update Schedule screen shows the update method that is in effect, currently. Click the Choices dropdown menu to change the update method:

  • Set Interval – Specify a custom interval, expressed in minutes, at which the CMS will seek and then push updates.
  • Every Day At – Specify a single time at which the CMS will seek and push updates every day.
  • Every Hour – This is the default method. Seek and push updates every hour. You must select this option to activate it.
