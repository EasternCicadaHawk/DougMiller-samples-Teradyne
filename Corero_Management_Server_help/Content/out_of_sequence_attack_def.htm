Out of Sequence Attack

Definition

The TCP out of sequence attack exploits TCP's connection-oriented behavior to deny service to legitimate users. One of TCP's features is that it handles data in the order that it is sent, which, under ordinary, legitimate circumstances, means that the data reaches the user in a sequential, understandable manner (think of simple examples such as a web page, an Email message, or a video segment). When TCP receives packets that are not in the correct order, it holds onto them until it has received them all and can arrange them in the correct sequence before providing them to the user. In addition, TCP does not limit the number of packets that can be buffered until they can be assembled sequentially; rather, this is a function of the target's memory. An attacker can abuse this feature by intentionally sending a very large number of TCP packets out of sequence, filling the target's memory, and therefore denying access to legitimate users.
