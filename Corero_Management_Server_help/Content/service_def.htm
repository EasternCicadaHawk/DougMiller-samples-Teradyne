Service Protocol

A service protocol specifies how traffic corresponding to a particular application is handled by the appliance. It comprises the transport protocol and port used by the application, and can include settings such as a connection timeout, a client group or another set of originating addresses, and characteristics such as discard priority, flow setup threshold, and request limiting. Service protocols are combined with server groups to make up server protection instances.

A large number of service protocols are built-in to the CMS and provided by default. You can modify these built-in service protocols or define your own custom ones, as necessary. Some of these built-in service protocols correspond to legitimate applications, or to applications that otherwise are not originally intended to be attack vectors, while others correspond to specific well-known attack vectors.
