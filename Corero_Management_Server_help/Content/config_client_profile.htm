Configure Client Profiles

Client profiles define sets of characteristics that constitute acceptable traffic behavior from clients. There are three types of client profiles: SYN flood profiles, connection limit profiles, and packet rate limit profiles. A number of profiles of each type are built-in, and you can create new ones as you see necessary.

In the web UI, click Manage Profiles in the Thresholds & Limits tab of the Client Groups screen to display the Client Profiles screen for creating new profiles and modifying existing ones. Alternatively, you can configure client profiles using the CLI command set defense profiles client-profiles.

A client profile is assigned to a client group as part of client group configuration.

Follow these steps to configure client profiles:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do
Access the controls for defining client profiles. Web UI: Defense Configuration > Client Groups to display the Client Groups screen. Select a client group, click the Thresholds & Limits tab, and click Manage Profiles to display the Client Profiles screen.

CLI: set defense profiles client-profiles

REST API: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/defense/profiles/client-profiles -d '{"syn-flood-profile": {"name": "profilename", "trusted-threshold": "60", "suspicious-threshold": "70", "suspicious-exit-threshold": "65", "malicious-threshold": "90", "proxy-requests-from-unknown-ip": "true"} }' --header "Content-Type:application/vnd.yang.data+json"

 This provides access to all the controls for defining client profiles. Note how the web UI combines this into client group configuration.
Define the client profile that you need. As above. There are three types of client profile:
  • SYN flood
  • Connection limit
  • Packet rate limit

Refer to the Client Groups screen for descriptions of the relevant controls.

When using the REST API, note that all three profile types must be created using the same profile name in order for the shared profile to be associated with a client group.
Save your changes when you're finished. Web UI: Save CLI: commit REST API: Save/commit occurs automatically upon execution of the cURL command.
