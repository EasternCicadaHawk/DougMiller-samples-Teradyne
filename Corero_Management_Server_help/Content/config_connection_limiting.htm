Configure Client Connection Limiting

This procedure configures an absolute limit on the number of connections that servers can accept from a client group or from all clients.

Configuring client connection limiting is an element of client group configuration. Click Defense Configuration > Client Groups in the web UI tool bar to display the Client Group screen. Alternatively, type the CLI command set defense profiles connection-limit-profile.

To configure client connection limiting:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do
Configure the connection limit values for an existing client group. Web UI: Defense Configuration > Client Groups in the web UI tool bar to display the Client Group screen. Select an existing client group and click the Thresholds & Limits tab. The important parameters are Maximum connections for this entire group and Maximum connections for any client in this group. You can choose an existing shared profile from the pulldown menu and use the values that are configured there, or click Use a custom profile to set new explicit values for the parameters.
CLI: set defense profiles client-profiles connection-limit-profile profilename max-group-connections value max-member-connections value Specify an existing connection limit profile to use its values, or define a new connection limit profile and configure explicit values for max-group-connections and max-member-connections.
REST API: curl -k -v -u admin:smartwall -X PATCH https://cmsipaddress/api/running/defense/profiles:profiles/client-profiles/connection-limit-profile -d '{"connection-limit-profile": {"name": "profilename", "max-group-connections": value, "max-member-connections": value } }' --header "Content-Type:application/vnd.yang.data+json"
Optional, for a custom client profile: Export the custom client profile for re-use later. Web UI: Click the link at the bottom of the Thresholds & Limits tab to display the Add New Shared Profile dialog. Type the name of the file to which you want to export the profile settings.
Save your changes when you're finished. Web UI: Save CLI: commit REST API:Save/commit occurs automatically upon execution of the cURL command.
