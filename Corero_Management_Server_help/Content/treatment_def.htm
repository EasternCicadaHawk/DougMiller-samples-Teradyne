Treatment

A treatment is a response taken by the appliance .when traffic bound for a server from a client group matches one or more profiles. A treatment consists of an action and, possibly, a log entry at some severity that are triggered when inbound traffic matches one or more client or server profiles.

Treatments use rule sets, also, to determine the way in which the appliance should respond to incoming traffic.
