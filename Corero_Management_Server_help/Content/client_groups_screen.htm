Client Groups screen

Click Defense Configuration > Client Groups to display the Client Groups screen for defining a list of IP addresses from which incoming traffic is handled the same way by the appliances. The same controls are available in the CLI by using the set defense profiles client-group command.

The Configure Client Groups topic describes how to define and modify client groups.

The Client Groups screen provides these controls:

Name – A descriptive identifier for the client group. This is all that is required to create the client group, though it isn't useful until the rest of fields are populated.

Add/Delete buttons – Click Add to display the Add New Group dialog box and define a new client group. The client group can be based on IP addresses or geographical locations (countries of origin).
Click Delete to remove a selected client group from the site.

Client Addresses and Ranges tab – Select an existing client group and click this tab to specify one or more IP addresses to include as members of the client group. For a geographical client group, select one or more countries to include in the client group.

  • IP Address/Range – For an IP address range client group, this shows the ranges of IP addresses that define the client group.
  • Subset Ranges Overview – If there are subsets of the IP address ranges that define the client group, this provides a graphical representation of where the subsets exist within the overall range. If there are no subsets, this field will say that there are no subranges.

Thresholds & Limits tab – Select an existing client group and click this tab to select or define a client profile that specifies what constitutes acceptable traffic from these clients.

  • Manage Profiles – Display the Client Profiles screen for working with client profiles independently of client groups.
  • Use a shared profile – Choose an existing client profile. The profiles High Limits, Low Limits, and Megaproxy Limits are built-in and provided by default.
  • Use a custom profile – Specify explicit values for the profile parameters:
    • Trusted client connection threshold (minimum) – The number of successful and well-executed connections required to establish this IP address as a trusted IP address. Requests from trusted clients are forwarded to the destination address.
    • Suspicious client connection threshold – The source IP address has reached a user-specified threshold (Suspicious Threshold) due to the number of open SYNs. The device will proxy all connection requests to any device from that source IP address.
    • Suspicious client connection exit threshold – The device maintains a count of the number of incomplete TCP connections destined to a server group and allows the user to set a value for this threshold (known as the Connection Threshold). When a source Client Group is in the Unknown or Trusted states, and the destination's Server Connection Threshold has not been reached, then SYN packets received from this source to the given destination are passed directly on to the server group (subject to other security policy checks).
    • Malicious client connection threshold – The source IP address has reached a user-specified threshold (Malicious Threshold) due to the number of open SYNs. The device will drop all connection requests to any device from that source IP address.
    • Initial treatment for clients in this group – Click Treat as trusted or Treat as suspicious (the default).
    • Maximum connections for this entire group
    • Maximum connections for any client in this group
    • Maximum packet rate for any client in this group – Specify the packet rate limit for this client.
    • Click here to export as a shared profile – Save the custom profile to a file so it can be re-used.
