Server Groups and Protection screen

Clicking Defense Configuration > Server Groups and Protection in the web UI tool bar displays the Server Groups and Protection screen for defining the set of responses that protect your server infrastructure when incoming traffic matches one or more profiles.

Optionally, you can access this functionality through several CLI commands:

  • For server protection instance configuration: set defense server-protection server-group
  • For server profile configuration: set defense profiles server-profiles
  • For client group configuration: set defense profiles client-group

Refer to Configuring Server Protection for instructions for configuring a server protection instance.

The Server Groups and Protection screen provides these controls:

  • Customer – This indicates the name of the customer associated with each server group. If no customer has been associated with the server group explicitly, the server group will be associated with the Default customer.
  • Server Group Name – This lists the server groups that have been defined for the site. Select a server group in this list to configure it or modify it.
  • Has Subsets – This indicates whether the IP address ranges that define the server group enclose any IP address range subsets.
  • Add/Delete buttons – Click Add to display the Add New Group dialog box for creating a new server group.
    Select an existing server group and click Delete to remove it from the site.
  • Server Addresses & Ranges tab – Select an existing server group and click this tab to specify one or more IP addresses to include in the server group.
    • Add/Delete buttons – Click Add to display the Add IP Address Range dialog box for specifying one or more IP addresses to include in the server group, or to define a subset of an existing address range.
      Select one or more IP addresses and click Delete to remove the addresses from the server group.
    • IP Address/Range – This shows the IP address ranges that define the server group.
    • Subset Ranges Overview – If there are subsets of the IP address ranges that define the server group, this provides a graphical representation of where the subsets exist within the overall range. If there are no subsets, this field will say that there are no subranges.
  • Thresholds & Limits tab – Select an existing server group and click this tab to select or define a server profile that controls how the server group responds to incoming flows. Each profile sets a value for SYN flood threshold, Maximum connections for this entire group, and Maximum connections for any server in this group.
    • Manage Profiles – Display the Server Profiles screen for working with server profiles explicitly.
    • Use a shared profile – Choose an existing server profile. The profiles High Limits, Low Limits, and Megaproxy Limits are built-in and provided by default.
    • Use a custom profile – Specify explicit values for the profile parameters.
      • SYN flood threshold – Specify a value for the maximum number of open SYN requests.
      • Maximum connections for this entire group – Specify the maximum total number of connections allowed for the server group.
      • Maximum connections for any server in this group – Specify the maximum number of connections allowed per individual member of the server group.
  • Server Protection tab – Select an existing server group and click this tab to configure the details of the server protection instance.
    • Protocol Group – Displays the protocol group associated with the server protection instance.
    • Client Group – Displays the client group associated with the server protection instance.
    • Traffic Treatment – Summarizes the set of responses the server group uses for flows from the protocol group and client group.
    • Add/Delete buttons – Click Add to display the Add Traffic Treatment dialog box and begin configuring the server protection instance. Click Delete to remove a selected server protection instance.
      Choose an existing Protocol Group and an existing Client Group and click Next to display the Protocol Group/Client Group dialog box for configuring the traffic treatment.
