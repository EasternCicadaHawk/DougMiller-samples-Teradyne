Cluster Configuration screen

Click Site Configuration > Cluster Configuration in the web UI tool bar to display the Cluster Configuration screen. This screen enables you to add Coreroappliances to the site and define the clusters and protection groups that are essential components of server defense.

The Cluster Configuration screen provides these controls:

  • Add/Delete – Clicking Add displays the Add a New Cluster dialog, described in the lines that follow. Clicking Delete removes a selected protection group from the site. The Add a New Cluster dialog provides these controls:
    • The Cluster Name Is – Type a unique descriptive name for a set of Coreroappliances that work together to handle inbound traffic on one network interface at a site.
    • The Cluster Has A – Indicate whether your Coreroappliances operate individually or have redundant counterparts.
      • Single Protection Group– Each Coreroappliance in the cluster operates individually, and does not have a redundant counterpart. This can include two load-balanced Defense appliances.
      • High Availability Pair of Protection Groups – Each Coreroappliance has a redundant counterpart in a different protection group. Both protection groups belong to the same cluster.
    • Each Protection Group Looks Like – Choose a representation of the Coreroappliances in your cluster. If you selected HA Pair, the CMS doubles the representation for you, with the redundant counterparts as members of a separate protection group.
    • Traffic Scale Parameter – Traffic Scale enables you to apply a multiple to global traffic parameters for the associated protection group. This is useful when the SmartWall appliances protecting your network use interface speeds other than 10 Gbps, for which the global defaults are intended. Traffic Scale is set to 1.0 by default; you can specify a value in x.y format, with one digit on each side of the decimal point.
    • The Device Settings Are – Type the IP address and a descriptive name for the appliance you are adding. The CMS will provide a default name based on the IP address that you provide and the appliance type.
    • Forensics Settings – Specify IP addresses and network masks for a Forensics appliance's interfaces.
    • Add – Click this button to execute the creation of the cluster.
  • Protection Group – The protection group name is derived automatically from the cluster name you specify.
  • Cluster Name – The cluster name you specified when you added the appliances to the site.
  • Config Preview – A graphical representation of the cluster you've defined.
