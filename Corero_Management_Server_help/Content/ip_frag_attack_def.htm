IP Fragmentation Attack

Definition

This is a catch-all term for a variety of different attacks that exploit the otherwise legitimate behavior of segmenting large IP packets across multiple data link layer frames. These exploits include fragments that overlap, that are malformed, that are incomplete, too large, or too small. In many cases, the higher level protocol's attempt to re-assemble what it perceives to be the original packet from the faulty fragments results in a packet that is invalid or otherwise unusable, in turn causing a processing delay or a memory problem. Multiplied across a very large number of such faulty fragments and invalid packets, the end result is the denial of service to legitimate users.

Observable characteristics

An unusually large number of data link layer frames, implying the presence of a large number of fragmented packets.

Method of response

Block any and all fragments that don't comply fully with expectations for legitimate fragments.

CMS configuration steps

None. The relevant rules are enabled by default.

  • cns-100018: IP fragment number exceeds maximum allowed
  • cns-100019: IP fragment reached maximum age
  • cns-100026: IP fragment size less than minimum length
