Capture Admin & Queries screen

Clicking Defense Monitoring > Capture Admin & Queries in the web UI tool bar displays the Capture Admin & Queries screen for administering queries of packet capture data acquired by a Forensics appliance. Alternatively, type the CLI command set forensics packet-capture query-management to access the same functionality.

Clicking on a query definition in the list shows its details, which can be edited.

The Capture Admin & Queries screen provides these controls:

  • Capture Mode – Choose Bypass, Capture, or Capture Until Full to indicate whether the Forensics appliance is acquiring data or not.
  • Add – Click this to display the Add New Query screen for defining a new query of existing packet capture data.
    • Query Name – A user-defined name for the query.
    • Query Start Time – Specify the time from which you want to begin filtering captured packets.
    • Query End Time – Specify the time at which you want to stop filtering captured packets.
    • Packet Length Min – Specify the smallest packet for which you want to filter.
    • Packet Length Max – Specify the largest packet for which you want to filter.
    • IP Protocol – Choose a protocol for which you want to filter.
    • Flow Direction – Choose Unidirectional or Bidirectional.
    • Ethertype – Choose the type of packet encapsulated by Ethernet frames.
    • Query Batch Size – Specify the number of bytes of data to include in each portion of the query you retrieve at one time.
    • Source IP Begin and Source IP End – Define a range of source IP addresses for which you want to filter.
    • Dest IP Begin and Dest IP End – Define a range of destination IP addresses for which you want to filter.
    • Source Port Begin and Source Port End – Define a range of source port numbers for which you want to filter.
    • Dest Port Begin and Dest Port End– Define a range of destination port numbers for which you want to filter.
  • Get Next Batch – Click this to retrieve the next portion of packet capture data included in the query.
  • Delete – Select an existing query definition to remove it. If the storage device associated with a Forensics appliance lacks sufficient space to collect a new query, the query fails and an alarm is generated. If this happens, delete some old queries to free space for the new query.
  • Status – This indicates the number of batches from the query that have been retrieved.
  • Batch Statistics – This indicates the number of packets processed and filtered for the most recent batch.
  • Query Statistics – This indicates the number of packets processed and filtered across all retrieved batches for the query.
