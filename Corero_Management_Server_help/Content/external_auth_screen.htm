External Authentication screen

Clicking External Authentication on the Users screen displays the External Authentication screen for configuring an external authentication regime for use with the CMS. You can access the same functionality using the CLI command set aaa external-authentication.

The External Authentication screen provides these controls:

  • Authentication Type – Choose Active Directory or RADIUS from the pulldown menu.
  • Server – Click Add to display the Server screen and define a new authentication server for the Authentication Type you selected.Type the server name, and choose its Admin state, Enabled or Disabled.
  • Reject If No Group – Select this if you want to deny all access to users if their profile does not belong to one of the groups mapped here. This is selected by default.
  • Group Mapping – Specify an external group to match to each of these built-in CMS groups:
    • Support
    • Admin
    • Defense
    • Monitor
    • No Access – Users and groups that are explicitly denied access to the CMS.
