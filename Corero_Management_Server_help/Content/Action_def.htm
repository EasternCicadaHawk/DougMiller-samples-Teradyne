Action

When traffic triggers a security rule, the appliance responds with an action, which is part of the treatment of a security policy. The supported actions are:

  • Allow: Pass the traffic to its destination.
  • Drop: Block the traffic passively by stopping the traffic with no indication to the originating client.
  • Reject: Block the traffic actively by stopping the traffic and executing a specific response, such as resetting the connection.

Each rule in a rule set has a user-modifiable action associated with it.
