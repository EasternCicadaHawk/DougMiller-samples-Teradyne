Configure ICMP Rate Limiting

ICMP rate limiting is configured as a packet cost.

To configure ICMP rate limiting:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do
Specify the cost for ICMP packets. Web UI: Defense Configuration > Advanced Security Controls in the web UI tool bar to display the Advanced Security Controls screen.

CLI: set defense profiles advanced-controls packet-costs icmp-packets value

REST API: curl -k -v -u admin:smartwall -X PATCH https://cmsipaddress/api/running/defense/profiles:profiles/advanced-controls/packet-costs -d '{"packet-costs": {"icmp-packets": value } }' --header "Content-Type:application/vnd.yang.data+json"

 Type a packet cost value in the ICMP Packets field.
Save your changes when you're finished. Web UI: Save CLI: commit REST API: Save/commit occurs automatically upon execution of the cURL command.
