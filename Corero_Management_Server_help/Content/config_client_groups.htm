Configure Client Groups

A client group is a list of IP addresses or countries from which incoming traffic is handled the same way by the appliances.

Click Defense Configuration > Client Groups in the web UI tool bar to display the Client Groups screen for defining and managing client groups. Alternatively, you can configure client groups using the CLI command set defense profiles client-group.

The CMS provides a single built-in client group named, "IP addresses not in a specific group". This is a default, catch-all client group that implicitly contains all client IP addresses that are not explicitly included in another client group. To be clear: a client IP address that is not explicitly included in a user-defined client group is implicitly included in the built-in client group named, "IP addresses not in a specific group".

Modify these settings to configure a client group:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do
Create the client group. Web UI: Click Add above the list of client group names to display the Add New Group dialog. Type the client group name, specify its type (IP Addresses or Geographical Locations), and click Add to create the group.
CLI: set defense profiles client-group clientgroupname group-type [ip | geographic] Type the name of the client group and specify whether it is an IP group or a geographic group.
REST API: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/defense/profiles/client-groups -d '{"client-group": {"name": "clientgroupname"} }' --header "Content-Type:application/vnd.yang.data+json" Specify the name of the client group.
Specify which IP addresses or countries are members of the client group, or members of any IP address range subsets that you want to define. Web UI: Select the client group name and click the Client Addresses and Ranges tab, then click Add to display the Add IP Address Range dialog or the Add Country dialog (as appropriate for the client group type). For an IP address client group, type the address or address range and click Add to include it in the group. For a geographic client group, choose one or more countries to include, then click Add.
CLI:

set defense profiles client-group clientgroupname addresses ipaddressrange
OR
set defense profiles client-group clientgroupname countries countryname

 Type the IP addresses or country names to include as members of the client group.
REST API: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/defense/profiles/client-groups/client-group/clientgroupname -d '{"client-addresses": {"ip-address": "ipaddressrange"} }' --header "Content-Type:application/vnd.yang.data+json"
Specify the threshold and limit values that make up the client profile. Web UI: Select the client group name and click the Thresholds & Limits tab. Choose an existing profile or specify custom values as necessary. The values are explained in the Client Groups screen.
CLI:
Specify an existing profile:
set defense profiles client-group clientgroupname assigned-profiles [connection-limit | packet-rate-limit | syn-flood]
OR create a custom profile:
set defense profiles client-profiles [connection-limit | packet-rate-limit | syn-flood] profilename		 Specify an existing profile by name or specify custom values as necessary. Note that the CLI exposes that the various threshold and limit values are actually divided between different types of profiles. Note also that profiles are assigned using a different command than that used to define them.
REST API: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/defense/profiles/client-profiles -d '{"syn-flood-profile": {"name": "profilename", "trusted-threshold": "60", "suspicious-threshold": "70", "suspicious-exit-threshold": "65", "malicious-threshold": "90", "proxy-requests-from-unknown-ip": "true"} }' --header "Content-Type:application/vnd.yang.data+json"  
Optional: Export the client profile for re-use later. Web UI: Click the link at the bottom of the Thresholds & Limits tab to display the Add New Shared Profile dialog.

CLI: The CLI handles client profiles separately from client groups, so there's no reason to export the profile explicitly.

 Type the name of the file to which you want to export the profile settings.
Save your changes when you're finished. Web UI: Save CLI: commit REST API: Save/commit occurs automatically upon execution of the cURL command.
