Traffic Scaling

The Traffic Scaling parameter, accessed in the Cluster Configuration screen, enables you to apply a multiple to global traffic parameters for the associated protection group. This is useful when the SmartWall appliances protecting your network use interface speeds other than 10 Gbps, for which the global defaults are intended. Traffic Scale is set to 1.0 by default; you can specify a value in x.y format, with one digit on each side of the decimal point.

Traffic Scaling is effective per protection group, and is displayed per protection group accordingly.

These parameters are affected by the Traffic Scale parameter:

  • Advanced Security Controls
    • UDP Global Rate
    • ICMP Global Rate
    • Non-TCP Rate
  • Threat Awareness parameters
    • Activation Parameters [New IP Addresses, TCP Setup Rate]
    • Exit Parameters [New IP Addresses, TCP Setup Rate]
  • Smart Rule parameters

Traffic Scale does not change the configured values of the affected parameters, but is applied to them as specified per protection group. Traffic Scale does not affect SYN limits and connection limits.
