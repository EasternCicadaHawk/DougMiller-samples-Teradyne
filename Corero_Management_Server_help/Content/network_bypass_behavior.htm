Network Bypass Behavior

The SmartWall Threat Defense System includes the Corero SmartWall™ Network Bypass Appliance, which provides the site with full network bypass capability. The Bypass appliance and the Bypass operating mode that it supports ensure that your server infrastructure will be accessible to users at all times, without interruption, even in the event of power failure, unpredictable equipment behavior, or planned maintenance interval.

Automatic Bypass vs. Manual Bypass

Bypass mode can be activated manually, by a user configuring Bypass mode explicitly through the CMS. A site or cluster also can be configured for automatic bypass; this occurs when the Bypass appliance stops receiving heartbeat from attached devices, and it switches from Inline or Monitor mode to Bypass mode, passing all incoming traffic along to the server infrastructure unimpeded, without it being inspected or treated in any way.

Bypass Behaviors

The Bypass appliance supports the following behaviors:

  • Inspection/Inline – This is Mitigate mode. Traffic is bridged between the Bypass appliance's inbound network port and its inbound inspection port. The traffic is handed off to the attached appliances, and, once their handling of the traffic is complete, the treated traffic re-enters the bypass appliance at its outbound inspection port, where it is bridged to the outbound network port for being passed to the server infrastructure.
  • Pure Bypass – This is Bypass mode. Traffic passes through the Bypass appliance directly from one network port to the other, without being passed to attached appliances, or being handled or treated in any other way.
  • Monitored Bypass (Tap) – This is Monitor mode. Traffic passes straight through the Bypass appliance, but is copied also to the inbound inspection port so that it can be handled by attached appliances. This is the auto Bypass mode.
