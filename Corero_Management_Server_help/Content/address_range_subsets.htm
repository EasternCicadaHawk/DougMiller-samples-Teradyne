IP Address Range Subsets

When defining host groups, it is possible to specify ranges of IP addresses that are subsets of other address ranges, as long as each subset is completely enclosed within its superset, and no address is a member of more than one range. Subsets can exist within the same host group, or they can be used to define other host groups. A range can consist of a single address. Overlapping address ranges are not allowed. This is useful if you need to create a specialized profile for a subset of clients or servers.

Address Range Rules and Examples

An address range can be defined as a numerical range (e.g., 10.1.1.1 - 10.1.1.255) or as a block (10.1.1/24). A single address can constitute a range, as well. A single IP address needs to be removed explicitly from one host group in order to be added to another.

Some examples follow, using two host groups (Hg1 and Hg2):

  • Hg1: 10.1.1.100; Hg2: 10.1.1.100 - 10.1.1.125 This does not overlap; the single address gets moved from the smaller range to the larger range.
  • Hg1: 10.1.1.125; Hg2: 10.1.1.100 – 10.1.1.150 This does not overlap; the single address gets moved from the smaller range to the larger range.
  • Hg1: 10.1.1.125; Hg2: 10.1.1.100 – 10.1.1.125 This does not overlap; the single address gets moved from the smaller range to the larger range.
  • Hg1: 10.0.0.0 – 10.255.255.255; Hg2 – 10.1.0.1 10.1.0.100 This does not overlap; the second range is completely enclosed within the first range.
  • Hg1: 10.1.0.10 – 10.1.1.20; Hg2: 10.1.1.15 10.1.1.25 The second range overlaps with the first, and this is not allowed.
  • Hg1: 10.1.0.10 - 10.1.1.20; Hg2: 10.1.1.20 10.1.1.25 The second range overlaps with the first, and this is not allowed.

Viewing IP Address Range Definitions in the CMS UI

In the CMS web UI, each server group and client group has a column next to its name titled Has Subsets, which indicates whether one or more of the address ranges that make up that host group is a superset of any other address ranges. In the Server Addresses & Ranges tab (for server groups) and the Client Addresses & Ranges tab (for client groups), there is one column for the IP Address/Range, and another column, Subset Ranges Overview, that provides a graphical representation of any subsets that have been defined. Floating the cursor over one of these bars displays a balloon summarizing the subset ranges that have been defined, as well as the names of the associated host groups.

The CLI command show defense address-summary host-group summarizes in text, for each server group and each client group (including the default server and client groups), the following address range information:

  • Configured Ranges – The address ranges that have been explicitly configured.
  • Enclosing Ranges – The address ranges that enclose other ranges.
  • Enclosing Hosts – The server or client groups that enclose the address ranges
  • Actual Ranges – The effective address ranges.
