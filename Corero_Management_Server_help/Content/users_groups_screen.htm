Users & Authentication screen

Clicking CMS > Users & Authentication in the web UI tool bar displays the Users & Authentication screen. This screen lists all user accounts defined locally in the CMS (this does not include user accounts defined externally), but only users with admin or support-level privileges can see users other than themselves. This screen provides controls for adding users and managing their access; click Add, Edit, or Delete to manage the set of existing user accounts. The same controls provided here are available using the CLI command set aaa.

The user accounts "admin" and "support" are provided by default.

Refer to AAA (Authentication, Authorization, and Accounting) Overview for a detailed description of AAA for the CMS.

NOTE: It is possible to delete the default user accounts, "admin" and "support". Selecting one of these accounts and clicking Delete will remove that account immediately, without prompting for confirmation first.

Click External Authentication to display the External Authentication screen for configuring the CMS to use a third-party authentication regime, such as Active Directory or RADIUS.
