Crafted IP Option Attack

Definition

A.k.a., the "Christmas tree" attack. In this attack, IP packets sent to the target have all of their possible options set, including combinations that are invalid. Used singly or in small numbers, these packets are useful as probes, as they can be used to determine what services reside on which interfaces at the target. Used in large numbers, these packets constitute a denial of service attack, as it takes the target a considerable amount of time to sort through all the options specified in each packet.

Observable characteristics

Rule cns-003006 triggers, indicating invalid TCP packets arriving at the interface.

Method of response

Block packets bearing flag combinations outside of a set of known valid combinations.
