Header Blocking screen

Clicking Defense Configuration > IP Packet Header Blocking in the web UI tool bar displays the Header Blocking screen for blocking traffic from entering your network based on its IP header type. Alternatively, type the CLI command set defense header-blocking to access the same functionality.

Refer to the Block IP Headers topic for instructions for blocking traffic by its IP header type.

The Header Blocking screen provides these controls, which are available also when using the CLI command set protection header-blocking.

  • IPv4 Packets - Choose Allow or Block. Allow is the default.
  • IPv6 Packets - Choose Allow or Block. Allow is the default.
  • IP Tunnels - Choose Allow or Block. Allow is the default.
