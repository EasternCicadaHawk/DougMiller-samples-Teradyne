Defense Mode

The Defense mode sets the overall traffic handling behavior for a site and for a protection group. The Defense mode can be set to one of the following:

  • Bypass – Incoming traffic is allowed to pass through the Corero appliance and into the network without being inspected or treated in any way. In this case, the appliance behaves simply as a wire.
  • Mitigate – Incoming traffic is inspected, logged, and treated as required by an applicable server protection instance.
  • Monitor – Incoming traffic is inspected and logged according to an applicable server protection instance, but is allowed to pass through to the network without being treated. This is the default Defense mode, and new Defense appliances are set to Monitor mode until they are configured explicitly to behave differently.

For a protection group, you can also choose Inherit Global, which causes the protection group to use the same setting specified for the site's Global Defense Mode.
