Field Blocking screen

Click Defense Configuration > Packet Field Blocking in the web UI tool bar to display the Field Blocking screen. Alternatively, you can access this functionality by typing the CLI command set defense field-blocking block-entry.

Field blocking enables you to configure up to four destination IP address/source port pairs as a means of mitigating DNS reflection attacks.

The screen provides the following controls:

  • Add/Delete buttons – Create a new field blocking or delete an existing one.
  • ID – Type a name for the field blocking.
  • Admin State – Choose Enabled or Disabled.
  • Dest IP – Type a destination IP address for the field blocking.
  • Source Port – Type a corresponding source port for the field blocking.
