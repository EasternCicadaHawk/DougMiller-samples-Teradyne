Introduction

This Getting Started Guide describes the essential steps that must be followed for every installation of the Corero SmartWall Threat Defense System. The tasks described here constitute the minimum set of actions that must be executed to have an operational Threat Defense System in place and ready to be configured to your organization's specific requirements.

SmartWall Threat Defense System installation comprises the following high-level actions, several of which comprise multiple more specific actions:

  • Installation Planning Checklist – This is a list of things you need to have available before you begin the installation process, such as adequate rackspace, virtual machine resources, and various IP addresses.
  • Installing the CMS – This is the set of actions you need to execute to install the CMS, such as configuring the virtual machine that will host it, installing the OVA, assigning the management IP address, and defining the server groups that you are protecting.
  • Basic Network Defense Configuration – Essential configuration tasks such as configuring user accounts and adding Corero appliances to the CMS configuration so they can be managed.
  • Installing and Configuring an Analytics Engine – Instructions for setting up a separate data analytics tool, such as Splunk. You can use any data anlytics tool you like. Corero works closely with Splunk, and Splunk is used for all analytics examples.
  • Provisioning Server Protection – Defining server groups and client groups, and the profiles that get assigned to them.
  • Testing Server Protection in Monitor Mode – Instructions for observing the behavior of your server protection instances without enabling them to treat traffic.
  • Reviewing and Refining Server Protection – Recommendations for tuning your server protection instances for achieving the performance you need from them.
  • Enabling Server Protection in Mitigate Mode – Activate the server protection instances to treat traffic.
