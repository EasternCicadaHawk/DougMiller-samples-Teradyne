Configure Packet Capture

Using packet capture as part of your SmartWall Threat Defense System involves the addition of a Forensics appliance and configuration of network storage for collecting the capture data, as well as configuration of one or more queries for searching that data. This topic summarizes the overall process of configuring packet capture support for your site.

Add a Forensics Appliance To The Site

Follow the procedure for Adding a Corero Appliance to Manage, making sure that it is a Forensics appliance. This is done in the web UI by clicking Site Configuration > Cluster Configuration. When you add the Forensics appliance, there are some additional things you need to do to configure the appliance. As you add the appliance, click Forensics Settings above the image of the Forensics appliance to display a set of pop-up fields for specifying the IP address and subnet mask for port 3 and port 4 on the Forensics appliance. One of these ports will connect to the storage infrastructure used for collecting data, and the other will connect to a Defense appliance.

Configure Network Storage

Follow the procedure for configuring the network storage that will collect the packet capture data. This is done in the web UI by clicking Site Configuration > Network Storage to display the Network Storage screen.

Add the portal. Click Add to display the Portal screen. Type a user-defined name for the storage entity and click Create. In the Host field, type the IP address or DNS hostname for the device. Type a port as well, or accept the default of 3260. Click Packet Capture in the tool bar path to return to the Packet Capture screen [same as the Network Storage screen].

Add the storage volume. Click Add in the Storage section to display the Storage screen. Type the volume name; this needs to be the formal volume name, as obtained via a system command. Then click Create to add the volume and begin configuring it. Specify the Device name; this is the Forensics appliance from which the network storage device receives data. Choose the Type of the storage device; this is Iscsi or RAM. Type the size of the device, expressed in GB. For Target, type the name of the PCAP file to which the data will be written. Specify an Admin state for the device, either Enabled or Disabled.

Configure Queries

Follow the procedure for configuring one or more queries for searching the data. This is done in the web UI by clicking Defense Monitoring > Capture Admin & Queries to display the Capture Admin & Queries screen. Choose Bypass or Capture to set the Capture mode; Bypass is the default. Click Add to display the New Packet Capture Query dialog box.

Return to the Basic Configuration Checklist if you're configuring your site for the first time.
