Creating an IP Access Control List

Blocking/always allowing an IP address adds that IP address to a list of addresses that is checked before any other part of the corresponding packet is examined. A list of blocked IP addresses often is referred to as blacklist, while a list of always-allowed IP addresses often is referred to as a whitelist. A packet from a blocked IP address is discarded immediately, and no additional processing is performed on any portion of its contents. Similarly, a packet from an IP address that is to be allowed always is forwarded immediately, with no additional processing.

Note: For either a blacklist or a whitelist, administratively enabling/disabling the list affects the rule associated with the list, and any corresponding notification. Once an address is added to a list, traffic from that address is always blocked (blacklist) or allowed (whitelist), even if the list itself is administratively disabled.

You can type a range as a spread of IP addresses (200.1.1.1 - 200.1.1.255), with a subnet mask (200.1.1.0 255.255.255.0) or as an offset (200.1.1.0/24).

A range of blocked or always allowed addresses is allowed to contain another range completely, but partial overlaps are not allowed. As long as each subset of addresses is completely enclosed within its superset, it is possible to nest address ranges as you require. The example that follows shows a range of whitelisted addresses that is completely enclosed within a range of blacklisted addresses:

  • 1.1.1.1 - 1.1.1.200 is blacklisted (blocking)
  • 1.1.1.101 - 1.1.1.199 is whitelisted (always allow)

This is valid, since 1.1.1.1 - 1.1.1.200 completely contains 1.1.1.101 - 1.1.1.199, and addresses in the smaller range (1.1.1.101 - 1.1.1.199) are always allowed. If necessary, you could even blacklist a range of addresses within that whitelist; say, 1.1.1.151 - 1.1.1.159. Priority is given to the smallest (most specific) range that contains a particular IP address; therefore, 1.1.1.153 would be blocked, even though it is contained also by a superset address range that is always allowed.

Click Defense Configuration > IP Access Control to display the IP Access Control screen for adding one or more IP addresses to the list. Alternatively, type set defense ip-access-control in the CLI.

 Specify one or more IP addresses or address ranges. In the web UI, make sure to click Create to add the addresses to the list. Choose Always Allow or Block from the Access menu to indicate how the addresses will be handled.
