About This Guide

This guide describes how to install a Corero SmartWall Network Threat Defense Appliance.

The release notes that are shipped with this product may differ from the information in this guide. In such a case, the information provided in the release notes is more recent and up-to-date than the information in this guide.

For support and the latest product information, please visit the Corero web site: (http://www.corero.com). Corero frequently updates this site with useful product information.

For detailed information on product configuration and management, refer to the documentation kit shipped with your SmartWall Network Threat Defense Appliance.

Audience

The guide is intended for use by network and/or security administrators who are responsible for installing and setting up network security equipment. Consequently, it assumes at least an intermediate level knowledge of computer hardware.

Accessing Information on the USB Flash Drive

A USB flash drive containing user documentation files is included with your SmartWall Network Threat Defense Appliance. The user documentation files on the USB flash drive are available in HTML and Adobe PDF.
