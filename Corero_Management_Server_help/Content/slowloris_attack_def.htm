Slowloris Attack

Definition

Slowloris is an attack aimed specifically at web servers, and is focused so tightly that it will leave other services running on the same host untouched. Slowloris works by initiating connections to the target and sending incomplete HTTP requests very slowly, thus consuming available connections and keeping them occupied as they wait for HTTP requests that never complete.
