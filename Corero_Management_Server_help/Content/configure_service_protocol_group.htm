Configure a Service Protocol Group

A service protocol group collects one or more related service protocols so that they can be used conveniently with a server group in a server protection instance. Click Defense Configuration > Service Protocol Groups in the web UI tool bar to display the Service Protocol Group screen. Alternatively, type set defense profiles service-protocol-group in the CLI.

To configure a service protocol group:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do
Name the new service protocol group. Web UI: Defense Configuration > Service Protocol Groups in the web UI tool bar to display the Service Protocol Group screen.

CLI: set defense profiles service-protocol-group serviceprotocolgroupname

REST API: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/defense/profiles/service-protocols -d '{"service-protocol-group": {"name": "serviceprotocolgroupname" } }' --header "Content-Type: application/vnd.yang.data+json"

 Type the name of the service protocol group to create it. In the web UI, click Create to finalize the addition of the service protocol group.
Include one or more service protocols in the group. Web UI: Click the service protocol group name to edit it. The Service Protocol screen appears.

CLI: set defense profiles service-protocol-group serviceprotocolgroupname service-protocol serviceprotocolname

 Specify one or more existing service protocols from the dropdown menu. You can create a new service protocol if you need to.
Save your changes when you're finished. Web UI: Save CLI: commit REST API: Save/commit occurs automatically upon execution of the cURL command.
