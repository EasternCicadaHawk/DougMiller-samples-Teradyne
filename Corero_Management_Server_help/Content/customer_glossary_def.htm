Customer

Each server group must have a customer name as part of its definition. There is a built-in customer named DEFAULT, so it is not necessary to define a new customer if you do not have multiple customers using your site. Although it is necessary to have a customer as part of each server group definition, customers are not binding in any other respect, nor do they contribute to any other definition. There are Rank and Status parameters associated with customers, but these are provided for use at the user's discretion. The Rank and Status parameters provide another means for customers to be sorted, but they do not contribute to the definition of any other aspects of the configuration.
