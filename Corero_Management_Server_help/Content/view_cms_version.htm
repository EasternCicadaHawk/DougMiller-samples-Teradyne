View CMS Version Information

To display software version information for the CMS:

  • Web UI: Click CMS > System Info in the web UI tool bar.
  • CLI: Type the CLI command show system
  • REST API: Type curl -k -v -u admin:smartwall -X GET https://cmsipaddress/api/operational/system --header "Accept: application/vnd.yang.data+json"
