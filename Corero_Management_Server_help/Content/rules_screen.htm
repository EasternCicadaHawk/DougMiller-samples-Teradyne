Rule screen

This screen lists packet rules or rate limit rules, depending on which you specified.

Click Defense Configuration > Security Rule Sets or Defense Configuration > IP Reputation Rule Sets to display this screen with a list of the corresponding rules. The CLI equivalents are set defense profiles rule-groups packet-rules rule and set defense profiles rule-groups rate-limit-rules rule.

The Rule screen provides these controls:

  • Rule Name – The rule identifier.
  • Admin State – Choose Enabled or Disabled for the rule. Mostly, rules are enabled by default, with a few exceptions.
  • Action – Choose what to do with traffic that triggers the rule:
    • Allow – Traffic that triggered the rule passes to its destination without restriction.
    • Detect – Traffic that triggered the rule is identified and logged, but is otherwise passed to its destination without restriction.
    • Block Active – Traffic that triggered the rule is stopped with no indication given to the originating client.
    • Block Passive – Traffic that triggered the rule is stopped and a specific response is executed, such as resetting the connection.
  • Log – Choose True or False, indicating whether to log the event or not when the rule is triggered.
  • Log Severity – The importance of the log message for the rule. Choose Minimal, Moderate, or Critical.
  • Description – The rule's short description.
  • Long Description – The rule's long description.
