Shunning screen

Click Defense Configuration > IP Address Shunning in the web UI tool bar to display the Shunning screen for defining and managing actions that block traffic from IP addresses immediately. Alternatively, type the CLI command set defense shunning shun-label to access the same functionality. The Shunning screen is a container for the Shun Label screen, which contains most of the controls for defining shunning actions.

Display the Shun Label screen by clicking on an existing shun label in the Shunning screen, or by clicking Add to create a new shun label. When you display this screen for an existing shun label, the screen is titled with the shun label name.

The appliance supports up to 256 shun labels.

Refer to Shunning Problematic IP Addresses for instructions for configuring a shunning action.

The Shun Label screen provides these controls:

  • Address – Type one or more IP addresses to block. This is useful when you want to block only a small number of IP addresses, and it's reasonable to type them individually. You can type a range as a spread of IP addresses (200.1.1.1 - 200.1.1.255), with a subnet mask (200.1.1.0 255.255.255.0) or as an offset (200.1.1.0/24).
  • File – Specify a file listing IP addresses to block. This is useful when you want to block a large number of IP addresses.
  • Duration – Choose a time interval to specify the amount of time for the affected addresses to be blocked. This is 4 hours by default, but you can choose intervals ranging from 5 minutes to 24 hours, as well as Unlimited, if you want to block the associated addresses permanently.
  • Ignore If Configured Address – Indicate whether this shunning action will supersede the default behavior for an associated client group or server group. This is selected by default.
  • Oper State – The effective status of the shun label. This is Pending by default.
