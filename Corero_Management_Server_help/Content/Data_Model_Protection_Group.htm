Protection Group Data Model

Access the Protection Group data model through Data Models > Protection Group > choose the name of the protection group you want to access. In the CLI, enter configure mode, then type "set protection-groups protection-group".

Click Add to provide the name of a new protection group and create it.

The Protection Group data model comprises the set of elements that must be configured for a protection group.

The Protection Group data model comprises the following elements:

  • Device List – The individual devices that are included in this protection group.
  • Used By Customer Service – The list of customer-facing services that are affected by this protection group.
  • Device Group – The individual device groups that are included in this protection group.
  • Rate Profiles – Access the Rate Profiles data model.
  • Network Services – Access the Network Services data model.
  • Client Groups – Access the Client Groups data model.
  • Server Groups – Access the Server groups data model.
  • Server – This section lists the server groups associated with this protection group. By default, these are the default server groups:
    • Allowed_Servers
    • Any
    • Any_Inbound
    • Any_Outbound
    • Forbidden_Servers
  • Shunning – Access the Shunning data model.
  • Header Blocking – Access the Header Blocking data model.
  • Check Sync – Compare the device configuration to the corresponding service.
  • Re-Deploy – Run the protection group logic.

The following additional controls are provided:

  • Device Modifications – This shows the actual configuration file text defined by the elements specified in the CMS.
  • Push Configuration To Devices – Select this if you want the protection group configuration to be sent to its constituent devices when the protection group is saved.
