Security Event Viewer

Click Defense Monitoring > Security Event Viewer in the web UI tool bar to display the Security Event Viewer.

The Security Event Viewer is a security monitoring and management tool in the web UI that enables you to easily examine and react to traffic that triggers security rules. The viewer includes features that enable you to filter and focus on security event details and take action immediately to address them.

The following controls are available for controlling the display of security events:

  • Pause – Suspend the display of new security events.
  • Resume – Show new security events again as they occur.

The Security Event Viewer lists the following information per security event:

  • Event Timestamp – The time at which the event was triggered.
  • Source IP Address – The IP address from which the traffic flow originated.
  • Source Port – The TCP port from which the traffic flow originated.
  • Destination IP Address – The IP address to which the traffic flow is directed.
  • Destination Port – The TCP port to which the traffic flow is directed.
  • Action – The response that the appliance takes for the traffic flow. This can be Allow, Block Passive, or Block Active.
  • Rule(s) Triggered – The specific rule(s) triggered by this traffic flow.
