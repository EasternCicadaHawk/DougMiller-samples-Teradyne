Operational Mode

The CMS CLI starts in operational mode. Use operational mode for displaying information about the CMS and the appliances that it manages. Use configure mode if you want to change some part of the configuration.

Operational mode provides the following commands:

  • compare – Compare running configuration to another configuration or a file
  • configure – Manipulate software configuration information
  • exit – Exit the management session
  • file – Perform file operations
  • help – Provide help information
  • id – Show user id information
  • quit – Exit the management session
  • request – Make system-level requests
  • script – Script actions
  • set – Set CLI properties
  • set-path – Set relative show path
  • show – Show information about the system
  • source – File to source
  • top – Exit to top level and optionally run command
  • up – Exit one level of configuration
