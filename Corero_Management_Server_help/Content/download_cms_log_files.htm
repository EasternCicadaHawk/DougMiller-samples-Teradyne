Pull Files From CMS screen

Clicking .CMS > Pull Files From CMS in the web UI tool bar displays the Pull Files From CMS screen. This provides access to several different CMS files that are useful for debugging problems or for replicating configurations.

Specify the type of file that you want to download:

  • Application Log – The downloaded file is "cms-app.log", which is useful for debugging some CMS-related problems.
  • Audit Log – The downloaded file is "audit.log", which is useful for debugging some CMS-related problems.
  • Configuration Checkpoint – The downloaded file is "config.audit.LATEST". This file lists configuration commands in CLI format, and is useful for reconstructing the CMS configuration.

Click Pull File From CMS to download the specified file type.
