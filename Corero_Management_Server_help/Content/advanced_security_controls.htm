Advanced Security Controls screen

Clicking Defense Configuration > Advanced Security Controls in the web UI tool bar displays the Advanced Security Controls screen. This screen enables you to specify custom costs for individual packet types, as well as rate limits for ICMP traffic.

These advanced security controls are available through the CLI using the set defense profiles advanced-controls command, except for the Header Blocking controls, which are available through the set defense header-blocking command.

Header Blocking:

Use these controls for blocking traffic from entering your network based on its IP header type. Each type of traffic is allowed by default, though you should note that MPLS traffic is affected by default by the administrative state of rule CNS-000071 (which is enabled by default).

  • IPv4 Packets – Choose Allow or Block. Allow is the default.
  • IPv6 Packets – Choose Allow or Block. Allow is the default.
  • MPLS Packets – Choose Inspect or Per Rule CNS-000071; the latter is the default.
  • IP Tunnels – Choose Allow or Block. Allow is the default.

Service Controls:

  • Outbound Packet Inspection – This is Disabled by default. Setting it to Enabled activates the inspection of traffic destined for the outside of the network.

ICMP Rate Limits:

  • ICMP V4 Rate
  • ICMP V6 Rate
  • ICMP V6 Priority Rate

Connection Rate Limits:

  • Non TCP Setup Rate – The rate at which non-TCP traffic will be allowed to pass through before triggering rule CNS-001022.

Fragmentation:

  • Max Age – Maximum fragment age in milliseconds before triggering CNS-100019.
  • Max Rate – Total number of fragments allowed per second.
  • UDP Fragmentation Ratio – Approximate number of fragmented packets allowed for every 100 non-fragmented packets.

Slow Client Checks:

  • Small Packet – A client packet with a TCP payload smaller than this is considered suspicious.
  • Small Packet Threshold – This number of consecutive small packets triggers CNS-003016.
  • Small Window – A client packet advertising a TCP window smaller than this is considered suspicious.
  • Small Window Threshold – This number of consecutive small windows triggers CNS-003017.

Probation Controls:

  • IP Address Timeout – When the Defense appliance recognizes that a DDoS attack is in progress and a new IP address is seen for the first time, that address is put "on probation" for the length of time (in seconds) specified by this parameter. If the IP address is seen again during this interval, it is taken off probation and promoted to being handled normally. Otherwise, if the IP address is not seen again during the interval, the original packet is dropped, and the next packet seen from that address (if any) will start the probation interval again.
