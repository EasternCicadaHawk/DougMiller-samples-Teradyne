Device Status screen

Display the Device Status screen by clicking Site Configuration > Device Status in the CMS tool bar. This screen enables you add, delete, and manage Corero appliances in the current site.

The Device Status screen provides these controls, which are available also when using the CLI command set devices device:

  • Status indicator icon – This icon shows the overall health of the appliance.
  • Alarms – If any alarms have been triggered on the appliance, this field shows the number of each category of alarm that is in effect currently.
  • Name – A descriptive, user-defined name for the appliance.
  • Address – The IP address or host name associated with the appliance's management interface.
  • Software Version – This identifies the build of software running on the appliance currently.
  • State – Indicates whether the appliance is in Mitigate, Monitor, or Bypass mode.
  • Uptime – The amount of time that has passed since the last time the appliance was rebooted.
  • Reachable – Indicates whether the device is reachable from the CMS or not.
  • Deployment State – Indicates whether the device's configuration is in-sync with the CMS, or whether a synchronization action is required to bring the appliance into accord with the CMS.
