Blocked & Detected Events Screen

Click Defense Monitoring > Blocked & Detected Events in the web UI tool bar to display the Blocked & Detected Events screen. This screen is a basic tool for monitoring suspicious traffic as it reaches your network's perimeter; it displays information about current attacks dynamically in real time, sorted by rule name.

Some of this information can be displayed in the CLI using the command show defense statistics rule-statistics rule-counts.

The following controls are available:

  • Clear counters for selected rules – Reset the event and packet count for each rule you've selected in the table.
  • Clear counters for all rules – Reset the event and packet count for every rule.
  • Search panel – Type a string to find its match in the contents of the Blocked & Detected Events screen.

The Blocked & Detected screen provides these controls:

  • Rule Name – The ID of a rule that was triggered when incoming traffic matched the characteristics specified in the rule.
  • Rule Description – The short description of the triggered rule.
  • Block Event Count – The number of times traffic was blocked as a result of triggering the rule.
  • Block Packet Count – The packet that causes the Blocked Event is also counted as one Dropped Packet. Any further packets that arrive for that flow are also dropped, but it still only counts as one event. This means the Dropped Packet Count is usually a larger number than the Blocked Event Count.
  • Detect Event Count – The number of times traffic was detected as a result of triggering the rule.
  • Detect Packet Count – The number of packets detected associated with this rule since the last time the counter for this attack was reset.

You can sort the contents of the Blocked & Detected Events screen by any column. The primary sort order is indicated by a caret (˄ or ˅, depending on the desired direction), and the secondary sort order is indicated by a plus sign (+).Once you choose a column by which to sort, you must refresh the Blocked & Detected Events screen to clear the current sort order and return to the default sort order, which is by rule number.
