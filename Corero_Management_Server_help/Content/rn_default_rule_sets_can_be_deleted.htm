The CMS web UI does not prevent the deletion of built-in rule sets

Currently, the CMS web UI allows the deletion of any built-in rule set; this is not the correct behavior. In addition, if you attempt to save the configuration after deleting the rule set, the system informs you, appropriately, that you can not delete built-in rule sets, but you have no way of preserving other unsaved configuration changes because the rule set is, in fact, gone. The only way to recover the rule set is to restart the CMS, discarding any other unsaved changes. Therefore, make certain to avoid deleting any built-in rule set.
