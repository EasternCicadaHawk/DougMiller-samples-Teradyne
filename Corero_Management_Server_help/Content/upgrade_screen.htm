CMS Upgrade screen

Clicking CMS > CMS Upgrade in the web UI tool bar displays the Upgrade screen, enabling you to change the version of CMS software that you're running.

Click the Browse buttons to select the package upgrade file and, separately, the base upgrade file.

Click Perform Upgrade when you're ready to proceed. Note that, when you do this, the CMS will restart and you will be logged out of your session.
