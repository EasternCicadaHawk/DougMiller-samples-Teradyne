Teardrop Attack

Definition

The teardrop attack is a type of IP fragmentation attack, combining overlapping packet fragments with excessively large payloads. If the target succeeds in re-assembling the overlapping fragments, it encounters an invalid and unmanageably large packet.

Method of response

 

CMS configuration steps

None. The relevant rules are enabled by default.

Relevant SmartWall rules

These rules pertain to this attack type:

  • cns-100005: IP fragment is overlapping
  • cns-100009: IP fragment reassembly exceeds max size
