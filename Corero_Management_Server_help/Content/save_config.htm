Save Your Configuration

Save your configuration frequently to ensure that the changes you make in the CMS are pushed to the appliance and are retained persistently.

Clicking Save in the web UI tool bar saves all configuration changes that have been made since the last save. By default, saving pushes the configuration changes to the Corero appliances managed by the CMS. The commit command in the CLI is equivalent to the Save button in the web UI.

Note: When using the REST API for configuration, Save/commit occurs automatically upon execution of each cURL command.
