Configure Server Connection Limiting

Click Defense Configuration > Server Groups & Protection in the web UI tool bar to display the Server Groups and Protection screen. Alternatively, type the CLI command set defense profiles server-profiles connection-limit-profile.

Configure server connection limiting:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do
Configure the maximum number of connections allowable for servers in the server protection instance. Web UI: Defense Configuration > Server Groups & Protection in the web UI tool bar to display the Server Groups and Protection screen. Select an existing server protection instance and click the Thresholds & Limits tab. The important parameters are Maximum connections for this entire group and Maximum connections for any server in this group. You can choose an existing profile from the pulldown menu and use the values that are configured there, or click Use a custom profile to set new explicit values for these parameters.
CLI: set defense profiles server-profiles connection-limit-profile connectionlimitprofilename max-group-connections limitvalue max-member-connections limitvalue Specify an existing connection limit profile or define a new one to set the values of the max-group-connections and max-member-connections parameters.
REST API: curl -k -v -u admin:smartwall -X PATCH https://cmsipaddress/api/running/defense/profiles:profiles/server-profiles/connection-limit-profile -d '{"connection-limit-profile": {"name": "connectionlimitprofilename", "max-group-connections": value, "max-member-connections": value } }' --header "Content-Type:application/vnd.yang.data+json"
Associate the connection limits with an existing server group. CLI: set defense server-protection DEFAULT servergroupname assigned-profiles connection-limit-profile connectionlimitprofilename This command associates the connection limit profile with the server protection instance. This is not necessary when using the web UI, since the profile is associated in context.
REST API: curl -k -v -u admin:smartwall -X PATCH https://cmsipaddress/api/running/defense/server-protection:server-protection/server-group/customername%2Cservergroupname/assigned-profiles -d '{"assigned-profiles": {"connection-limit": "connectionlimitprofilename" } }' --header "Content-Type:application/vnd.yang.data+json"
Save your changes when you're finished. Web UI: Save CLI: commit REST API: Save/commit occurs automatically upon execution of the cURL command.
