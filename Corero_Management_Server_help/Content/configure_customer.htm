Configure Customers

Customers are associated with server groups and server protection instances. Although it is necessary to have a customer as part of each server group definition, customers are not binding in any other respect, nor do they contribute to any other aspect of the configuration. There are Rank and Status parameters associated with customers, but these are provided for use at the user's discretion. The Rank and Status parameters provide another means for customers to be sorted, but they do not contribute to the definition of any other aspects of the configuration.

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.
