SNMP screen

Click CMS > SNMP in the web UI tool bar to display the SNMP screen for configuring the site's SNMP behavior. The same functionality is accessible via the CLI command set snmp.

The SNMP screen provides these controls:

  • Agent – Display the Agent screen for configuring the SNMP agent used by the CMS.
    • Enabled – Click this to activate the SNMP agent.
    • IP – Specify the IP address on which the SNMP agent will listen for notifications. Keep the default.
    • UDP Port – Specify the UDP port that the SNMP agent will use for communicating. The default is 161.
  • System – Type descriptive information for the person responsible for administering SNMP for this CMS.
    • Contact
    • Name
    • Location
  • Target – Display the Target screen to define a destination for the SNMP traps that the CMS sends.
    • Name – A descriptive name for the trap recipient.
    • IP – The trap recipient's IP address.
    • UDP Port – The UDP port on which the recipient listens for traps. The default is 162.
    • Tag – Any specific tag values used to identify the recipient address.
    • Timeout – This is for SNMP v3 only.
    • Retries – This is for SNMP v3 only.
    • Engine ID – This is for SNMP v3 only.
  • Community – Display the Community screen for defining a new SNMP community.
    • Index
    • Name
    • Sec Name
    • Target Tag
  • Notify – Display the Notify screen for defining additional notification targets.
