Upgrade Corero Appliance Software

This topic describes the process of upgrading the software on any Corero appliance:

  • SmartWall Network Threat Defense Appliance
  • SmartWall Network Bypass Appliance
  • SmartWall Network Forensics Appliance

Click Site Configuration > Push files/images in the web UI tool bar to display the Push Files/Images screen for upgrading the software of one or more of the Corero appliances in your site.

(The screen and the procedure are the same in the event that you ever decide to roll your appliance software back to an earlier version, as well.)

To upgrade Corero appliance software:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do
Upload the new software image to the CMS if you have not done so already. Web UI: Site Configuration > Push files/images, then click the Device Firmware tab. Click Add to display the Upload Device Firmware dialog. Specify the location where the image you want to upload resides, then specify the file name you want the image to have on the CMS if you don't want to use the image's original name. Click Upload to execute the transfer. The software image is added to the list in the Device Firmware tab.
Push the software image to one or more Corero appliances in the site. Web UI: In the Device Firmware tab, select the software image you want to distribute to one or more appliances. Click Push selected file to a single device and select it from the pulldown menu, or click all devices to push it to every appliance in the site.

Recommended: Click Install and activate this image after transferring if you want the new image to be loaded and used immediately.

Click Push File(s) to execute the distribution of the selected software image.
Save your changes when you're finished. Web UI: Save

NOTE: Make sure to Save your configuration after making any changes using the Push Files/Images screen to ensure that information about those changes is retained properly. For example, if you upload a file to the CMS for distribution to Corero appliances, but exit the CMS before saving the configuration change, the file will be present in the directory to which it was uploaded, but will not be shown in CMS configuration.
