Security Rule Set screen

The Security Rule Set screen enables you to manage security rule sets for the site. Security rule sets describe behaviors for identifying and addressing traffic based on the nature of the traffic itself, such as its packet formation or its content.

Click Defense Configuration > Security Rule Sets in the web UI tool bar to display the Security Rule Set screen, or use the CLI command set defense profiles rule-groups security-rule-set to access the same functionality.

Refer to Configuring Server Protection to learn how rule sets are associated with server protection instances.

The Security Rule Set screen provides these controls:

  • Add/Delete buttons – Define a new Security rule set to add it to the collection of rule sets that are available to the site, or remove an existing rule set.
  • Name – A descriptive name for the rule set. The names of built-in rule sets provide some indication of each rule set's purpose.
  • Description – An optional, more verbose explanation of the rule set's purpose.
  • Block Active – True or False. Traffic that triggered the rule is stopped with no indication given to the originating client.
  • Default Log – This indicates whether a log entry should be made when a rule in the rule set is triggered.
  • Copy Of – If this rule set was created initially by copying another, this tells which rule set was used as the seed for this one.

If you decide to change the configuration of a rule set, you should do that using a copy, preserving the original rule set for reference.
