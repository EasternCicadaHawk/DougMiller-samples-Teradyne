Block IP Headers

You can block traffic from entering your network based on its IP header type.

Click Defense Configuration > Advanced Security Controls to display the Advanced Security Controls screen. Alternatively, configure header blocking using the CLI command set defense header-blocking.

To block by IP header type:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do
Specify the header types that you want to block. Web UI: Defense Configuration > Advanced Security Controls to access the packet header types.

CLI: set defense header-blocking [ip-tunnels | ipv4-packets | ipv6-packets] [allow | block]

REST API: curl -v -k -u admin:smartwall -X POST https://cmsipaddress/api/running/defense/header-blocking -d '{"ipv6-packets": "block"}' --header "Content-Type:application/vnd.yang.data+json"

 Specify Block for any header type that you want to exclude. Note that all header types are allowed by default.

 

The REST API example shows how to set a header type to "block"; IPv6 in this case.
Save your changes when you're finished. Web UI: Save CLI: commit REST API: Save/commit occurs automatically upon execution of the cURL command.
