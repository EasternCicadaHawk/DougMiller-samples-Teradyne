Installing a SmartWall Network Threat Defense Appliance in the Rack-Mount Sleeve

This section describes how to install a SmartWall Network Threat Defense Appliance using the optional rack-mount sleeve available for use with the SmartWall Network Threat Defense ApplianceIt is written with the assumption that you have already installed the rack-mount sleeve as described in Installing the Rack-Mount Sleeve.

To prevent the SmartWall Network Threat Defense Appliances from overheating, do not operate them in a space that exceeds the recommended ambient temperature of 0°C to 40°C (32°F to 104°F).

To prevent airflow restriction, allow at least 3 inches (7.6.cm) of clearance around the ventilation openings.

If you are mounting more than one hardware device in the rack, mount the larger devices near the bottom of the rack, and always begin mounting hardware from the bottom of the rack and add devices upward in order to avoid uneven or unbalanced loading.

  1. Unpack the SmartWall Network Threat Defense Appliance from its shipping container and place it on a firm, level surface.
  2. Identify the slot in the rack-mount sleeve into which you want to insert the SmartWall Network Threat Defense Appliance.
  3. Insert the SmartWall Network Threat Defense Appliance into the slot in the rack-mount sleeve slowly and carefully. A latch on each side of the SmartWall Network Threat Defense Appliance will engage with the inside of the slot at an opening provided for securing the SmartWall Network Threat Defense Appliance in place. These latches will hold the SmartWall Network Threat Defense Appliance in the correct position in the sleeve. Be cautious not to insert the SmartWall Network Threat Defense Appliance too quickly; if you insert it too quickly for the latches to engage, it is possible to push the SmartWall Network Threat Defense Appliance through the back of the sleeve.
  4. Verify that the latches have engaged and the SmartWall Network Threat Defense Appliance is securely in place.
