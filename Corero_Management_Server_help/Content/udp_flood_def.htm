UDP Flood Attack

Definition

A UDP flood attack is a volumetric attack, a flood of UDP packets. Typically, a UDP attack consists of a huge number of packets directed at randomly selected ports on the target server. The target responds by checking to see what applications it might have listening on those ports, and, if no application is listening there, the server responds with an ICMP Destination Unreachable message. The huge number of inbound requests combined with the similarly huge number of responses traveling outbound consumes the server's bandwidth, making it unreachable by legitimate users.

CHARGEN attacks are a variant of UDP flood attack that use the technique of amplification; outgoing CHARGEN responses return much larger packets than the incoming requests.

Observable characteristics

High UDP rates from distributed spoofed sources.

Method of response

Block UDP-based requests and responses.

CMS configuration steps

Rules cns-001028, cns-001029, and cns-001032 are enabled by default and stop NTP and uPNP attacks. cns-001032 is enabled by default, but is set to Detect. If it is triggering at a high rate, it should be set to Drop instead of Detect.

Relevant SmartWall rules

These rules pertain to this attack type:

  • cns-001022: Non-TCPRateLimit - Excessive non-TCP connection rate.
  • cns-001028: NTP MONLIST response blocked
  • cns-001029: NTP MONLIST request blocked
  • cns-001032: uPNP reply blocked
  • cns-002005: ClientPacketRateLimit - rate from client to enabled services exceeds specified limit
  • cns-002006: ClientPacketRateLimit - packet rate from client exceeded overdraft threshold
