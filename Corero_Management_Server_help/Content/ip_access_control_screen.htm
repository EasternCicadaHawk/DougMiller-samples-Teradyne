IP Access Control screen

Clicking Defense Configuration > IP Access Control in the web UI tool bar displays the IP Access Control screen. This screen enables you to define access control instances to always block (blacklist) or always allow (whitelist) traffic from a specified IP address or range of IP addresses. Blocking/always allowing an IP address adds that IP address to a list of addresses that is checked before any other part of the corresponding packet is examined. A packet from a blocked IP address is discarded immediately, and no additional processing is performed on any portion of its contents. Similarly, a packet from an IP address that is to be allowed always is forwarded immediately, with no additional processing.

The IP Access Control screen provides these controls:

Add/Delete – Create or remove an entry. Click Add to display the Add New IP Access Control screen.

  • Name – Type a descriptive name for the blacklist or whitelist.
  • Source IP – Type the source IP address or range to include in the access control instance. You can type a range as a spread of IP addresses (200.1.1.1 - 200.1.1.255), with a subnet mask (200.1.1.0 255.255.255.0) or as an offset (200.1.1.0/24). Refer to Creating a Blacklist or Whitelist of IP Addresses for instructions about nesting address ranges, if you need to do that.
  • Admin State – Choose Enabled or Disabled.
    Note: For a whitelist, this enables/disables the rule associated with the list, and any corresponding notification. Once an address is added to a whitelist, traffic from that address is always allowed, even if the whitelist itself is administratively disabled.
  • Access – Choose Block for a blacklist or Always Allow for a whitelist.

The equivalent CLI command is:

set defense ip-access-control access-control-entry name access [always-allow | block] admin-state [enabled | disabled] source-ip ipaddress

The equivalent REST API command is:

curl -k -v -u admin:smartwall -X PATCH https://cmsipaddress:443/api/running/defense/ip-access-control/access-control-entry/ -d '{"access-control-entry": {"name": "listname", "access": "block", "admin-state": "enabled", "source-ip": "ipaddress" } }' --header "Content-Type:application/vnd.yang.data+json"
