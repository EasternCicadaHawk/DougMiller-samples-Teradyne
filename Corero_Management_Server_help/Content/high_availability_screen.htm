High Availability screen

Click CMS > High Availability in the web UI tool bar to display the High Availability screen and configure a virtual IP address to be shared across both CMS instances in a redundant CMS pair. The same functionality is available in the CLI using the set high-availability command.

The configuration that is required for each CMS instance in the pair to recognize the other is done with the assistance of Corero customer support at installation time.
