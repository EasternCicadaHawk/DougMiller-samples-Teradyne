CMS Dashboard

The CMS dashboard appears by default when you log in to the CMS, displaying a number of graphs and tables that, together, summarize the overall threat status of the traffic seeking entry to your network. You can re-display the dashboard at any time by clicking Home in the path in the web UI tool bar.

Security Rule Block Rates (per second)

This tool graphs the rates at which rules of the different major categories are triggered on your Defense appliances by incoming traffic. This provides a broad sense of the type of unwanted traffic that your network is encountering, providing insight into possible attack methods. The graph is refreshed every 60 seconds.

Every 60 seconds the CMS creates a report that summarizes rate of packet blocking in the system for each of the overall classifications for security rules on the Defense appliances.

This tool graphs these statistics:

  • All Rules – The total rate of packet blocking for all rules in the system.
  • Access Restriction Rules (Network Threats) – The rate of packet blocking for rules of the ARNET classification.
  • Rate Limit Rules (Network Threats) – The rate of packet blocking for rules of the RLNET classification.
  • Protocol Validation Rules (Network Threats) – The rate of packet blocking for rules of the PVNET classification.
  • Integrity Analysis Rules (Network Threats) – The rate of packet blocking for rules of the IANET classification.
  • Integrity Analysis Rules (Application Threats) – The rate of packet blocking for rules of the IAAPP classification.

This information is carried in Block Rate Statistics Type syslog messages.

Excessive Rate Indications (per second)

This tool graphs these statistics:

  • TCP Setup Rate – The current TCP flow setup rate.
  • Non-TCP Setup Rate – The current non-TCP flow setup rate.
  • Protocol Validation Block Rates – The rate of packet blocking for rules of the PVNET classification.

This information is carried in Setup Rate Statistics Type and Block Rate Statistics Type syslog messages.

IP Address Classifications (counts)

This tool graphs these statistics:

  • In Use Trusted Addresses – IP addresses in use classified as trusted.
  • In Use Suspicious Addresses – IP addresses in use classified as suspicious.
  • In Use Malicious Addresses – IP addresses in use classified as malicious.
  • In Use Unclassified Addresses – IP addresses in use not yet classified.

This information is carried in IP Address Classifications Type syslog messages.

Top Recent Service Ports

This lists the service ports most used recently by incoming traffic. They are listed by protocol and their percentage of overall use.

Top Recent Clients

This lists the clients to have sent the most traffic to your network recently. They are listed by IP address and their percentage of the overall traffic.

Top Recent Servers

This lists the servers in your network to have received the most traffic recently. They are listed by IP address and their percentage of the overall traffic they've received.

Top Recent Security Events

This lists the rules most triggered recently by incoming traffic. They are listed by rule and their percentage of the overall traffic.

Mission Port Rates (Mbps)

  • External Port Bit Transmit Rate – External mission port(s) aggregrate rate.
  • Internal Port Bit Receive Rate – Internal mission port(s) aggregrate rate.

Summary Packet Rates (per second)
