Reference Information

Reference information comprises a variety of detailed descriptions and definitions that give in-depth background for the overviews and step-by-step instructions that appear in other sections.

  • The Concepts and Explanations section provides detailed explanations of how the appliance and CMS work.
  • The Screen and Command Descriptions section describes the controls that appear in each CMS screen.
  • The Glossary provides brief definitions of terms that have special meaning in the behavior of the Corero appliance and CMS.
  • The Configuration Data Models section provides detailed descriptions of the sets of elements that enable you to configure the appliance and the CMS.
  • The Command Line Interface section provides an introduction to the CMS CLI.

Descriptions of how to execute tasks in the CMS and configure the appliance appear in non-reference sections such as Configuring Basic Behavior, Analyzing Traffic, and Blocking Threats.
