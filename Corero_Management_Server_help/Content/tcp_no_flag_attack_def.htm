TCP No Flag Attack

Definition

A.k.a., a TCP null packet. This attack uses TCP packets with no flag set (no SYN, ACK, or RST), which makes the packet invalid. These packets are useful probes for identifying open ports on a target., and they may be used in combination with one or more other types of attack during a denial of service attack.
