CMS Backup/Restore screen

Clicking CMS > CMS Backup/Restore in the web UI tool bar displays the CMS Backup/Restore screen, providing controls for saving and reloading the CMS configuration. Configuration backups (backup bundles) are created for a specific CMS version.

Note: No more than one backup is retained on the CMS file system(s) at any one time.

The CMS Backup/Restore screen provides these controls:

  • Time the most recent backup was performed.
  • Create Backup – Save the current CMS configuration to a file.
  • Browse – Navigate the filesystem to locate a CMS backup bundle from which to restore the configuration.
  • Restore Backup – Reload the selected CMS configuration file. Note that the CMS will restart as soon as the restoration is complete.

The same functionality is available through the CLI by using the command request backup [create | restore] file filename.
