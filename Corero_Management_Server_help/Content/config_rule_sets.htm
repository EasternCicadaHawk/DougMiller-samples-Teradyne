Configure Rule Sets

A rule set is a named collection of rules that is configured to identify and address traffic for a particular purpose. Rule sets provide basic responses to traffic that matches certain characteristics. User-defined rule sets can be created from built-in rule sets, and existing rule sets can be modified. The CMS divides rule sets broadly into two categories: security rule sets and reputation rule sets.

You can configure the treatment for a particular rule to be different for different rule sets, and you can modify the treatment applied to individual rules within a set. A treatment modification applies only to the instance of the rule associated with that named rule set.

Follow this procedure to configure security rule sets or reputation rule sets. Note that instructions for creating new rule sets are included, also.

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

  • Block Active
  • Default Log
  • Description

CLI: Type the name of a new rule set to create it.

Optional: Specify which rules should be enabled or disabled in the rule set. Web UI: Click Rules in the screen for a particular rule set to display the Rule screen.

CLI: set defense profiles rule-groups security-rule-set rulesetname rules rule rulenumber admin-state [enabled | disabled]

 Specify a rule in the rule set and change its admin state to Enabled or Disabled as necessary.
