TCP SYN Fragment Attack

Definition

The TCP SYN fragment attack is a variation on the SYN flood attack that uses incomplete TCP SYN messages. In this attack, the target is inundated with incomplete TCP SYN messages, which it collects and holds onto while it waits for the rest of the message to re-assemble the corresponding packet. In actuality, the rest of the message is never sent, the packet never gets re-assembled, and the target's memory buffer fills up with incomplete SYN fragments, resulting in an inability for legitimate traffic to connect.

Observable characteristics

 

Method of response

Block any packets bearing an incomplete SYN message.

CMS configuration steps

None. cns-003027 is enabled by default.

Relevant SmartWall rules

This rule pertains to this attack type:

  • cns-003027: TCP SYN packet fragmented
