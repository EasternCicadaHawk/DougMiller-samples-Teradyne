CMS Web UI Tool Bar

The tool bar across the top of the CMS web UI provides convenient access to all the screens and controls in the web UI, making it easy to configure custom security for your servers in a simple series of clicks across just a few screens for any configuration task. Most CMS functionality supports server protection, enabling you to define and manage profiles and other definitions for protecting your critical network infrastructure.

  • Defense Monitoring – Display high-level summaries of what is happening in the site; these include Security Event Viewer and Blocked and Detected Attacks. In addition, administer packet recording and forensics queries using the Packet Capture screen.
  • Defense Configuration – Configure protection for your servers. This includes IP Address Shunning, IP Packet Header Blocking, Client Security Profiles, Server Security Profiles, and Server Protection.
  • Site Configuration – Administer Corero appliances and manage their software.
  • CMS – Administer the CMS itself, including users, customers, syslog and SNMP access, and redundancy (high availability).
  • CLI – Access the command line interface as an alternative means of configuring the appliance.
  • Help – Access this help set for descriptions of CMS screens and controls, and instructions for configuring various behaviors. The Help menu provides several entry points to the help set, including the ability to search for a particular string.
  • Save – Retain changes you've made to the configuration and distribute them to the devices you're managing. Refer to Save Your Configuration for a detailed description.
  • Status icons – Beneath the main menu bar is a series of icons that summarize the site's status. A green icon indicates that there are no problems; while an orange icon indicates that your attention is required in that area. Each icon is accompanied by a number that indicates the number of objects requiring your attention. Floating the cursor over the icon displays a balloon containing a brief descriptive summary of the associated status.
    • Uncleared Alarms – Click this icon to display the Alarm Center screen.
    • Configuration – Click this icon to display the Device Status screen or to immediately deploy the latest saved CMS configuration to any out of sync appliances.
    • Connectivity – Click this icon to display the Device Status screen or the Cluster Configuration screen.
    • Notifications – Click this icon to display or clear notifications.
