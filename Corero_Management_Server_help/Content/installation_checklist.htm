Installation Planning Checklist

Prior to installing your SmartWall Threat Defense System in its various components, you will need to prepare the following things:

  • Rackspace in your datacenter. Each Corero appliance needs one-quarter of a standard rack unit. In addition, you will need to allocate rack space for the server hardware you will use to host the virtual machines required for the solution.
  • Three separate virtual machines. You'll need one for the CMS, one for SecureWatch, and one for Splunk.
  • An IP address for each Corero appliance.
  • An IP address for each CMS instance.
  • The IP address of your network's default gateway.
  • The IP address of your network's DNS server.
  • The IP address of your network's NTP server.
  • The IP address of at least one syslog server.

Each of these items will be needed at some point in the process of installing the CMS.
