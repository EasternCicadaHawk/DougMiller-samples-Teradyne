Shun Label screen

Display the Shun Label screen by clicking on an existing shun label in the Shunning screen, or by clicking Add to create a new shun label. When you display this screen for an existing shun label, the screen is titled with the shun label name. The Shun Label screen is a subset of the Shunning screen, and is nested within it.

The appliance supports up to 256 shun labels.

The Shun Label screen provides these controls:

  • Address – Type one or more IP addresses to block. This is useful when you want to block only a small number of IP addresses, and it's reasonable to type them individually.
  • File – Specify a file listing IP addresses to block. This is useful when you want to block a large number of IP addresses.
  • Duration – Choose a time interval to specify the amount of time for the affected addresses to be blocked. This is 4 hours by default, but you can choose intervals ranging from 5 minutes to 24 hours, as well as Unlimited, if you want to block the associated addresses permanently.
  • Override Host Group – Indicate whether this shunning action will supersede the default behavior for an associated client group or server group. This is selected by default.
  • Bi-Directional – Indicate whether this shunning action applies to traffic in both directions from the protected devices. This is selected by default.
  • Admin State – The configured status of the shun label, Enabled or Disabled. Enabled is the default.
  • Oper State – The effective status of the shun label. Pending by default.
