TCP Zero Window Attack

Definition

The TCP receive window size is a buffer that controls the amount of data that a TCP connection can accept and prepare for processing. In this attack, the attacker sends TCP packets with the TCP window size intentionally set to 0, rendering the connection unable to accept data.

The TCP window attack is a variant of sockstress attack.
