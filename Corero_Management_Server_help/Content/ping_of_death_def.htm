Ping of Death Attack

Definition

The ping of death is a type of ICMP attack that causes the target to assemble excessively large (and therefore invalid) IP packets from multiple fragments.

The maximum allowable size of an IP packet is 65,535 bytes, and any packet that exceeds that size is characterized as "malformed" and invalid. Restrictions in data link protocols such as Ethernet, however, require large IP packets to be fragmented across multiple smaller frames. Ethernet, for example, has a maximum frame size of 1500 bytes, so a maximum sized IP packet would be fragmented across 44 Ethernet frames. Upon reaching the destination, the fragmented IP packet is re-assembled to its original size. The ping of death exploits this mechanism by sending fragments containing more than 65,535 bytes, resulting in a malformed packet upon re-assembly at the target. The malformed packet can overflow its assigned memory buffer; multiplied by a very large number of such packets, this can result in denial of service to legitimate users.

Observable characteristics

Incoming ICMP frames that, in combination, will constitute an excessively large IP packet.

Method of response

Block ICMP frames that, in combination, will constitute an excessively large IP packet.
