cns-003002

Description: PVNET: IP frame destination address equals source addr-LanD

Long Description: This rule detects packets associated with the LanD attack (typically created using an attack program named land.c). The land.c program launches a denial-of-service (DoS) attack by sending a TCP SYN packet (a connection request) giving the target host's address as both the source and destination address, and using the same port on the target host as both the source and destination port. This attack makes it appear that the host computer is sending packets to itself. Servers, that do not properly validate the input socket pair, can experience TCP/IP stack overflows.
