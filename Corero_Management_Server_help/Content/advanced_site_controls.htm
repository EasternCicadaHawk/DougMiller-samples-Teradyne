Advanced Site Controls screen

Clicking Site Configuration > Advanced Site Controls in the web UI tool bar displays the Advanced Site Controls screen. These controls specify a variety of global defaults for the CMS and the site that it manages.

The Advanced Controls screen provides these controls:

Packet Processing

  • Base Sampling Period – Choose Short, Medium, or Long. Medium is the default.

Device Communications

  • Security Event Port – The default is 6343.
  • Sampled Packet Port – The default is 6343.
  • Syslog Port – The default is 11222.
  • SNMP Trap Port – The default is 162.
  • SNMP Community – The default string is smartwall.
