CMS Management Elements

Most CMS functionality supports server protection, enabling you to define and manage profiles and other definitions for protecting your critical network infrastructure.

  • Security Monitoring – Display high-level summaries of what is happening in the site. These include Security Event Viewer, Blocked and Detected Attacks, and Active Service Protocols.
  • Security Configuration – Configure protection for your servers. This includes IP Address Shunning, IP Packet Header Blocking, Client Security Profiles, Server Security Profiles, and Server Protection.
  • Site Configuration – Administer appliances and other devices. Also, manage software
  • Advanced – Use sparingly and with great caution. This provides direct access to the data models that make up the appliance configuration.
  • CLI – Access the command line interface as an alternative means of configuring the appliance.

In addition, the CMS dashboard serves as the CMS's home page.
