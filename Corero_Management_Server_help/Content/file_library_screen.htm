File Library screen

Click .Site Configuration > File Library in the web UI tool bar to display the File Library screen.

The File Library screen provides these controls:

  • #
  • Name
  • URL
  • Type
  • Direction
  • Date
  • Status
  • Push File to Device – Specify a device to which to send the configuration loaded currently in the CMS.
  • Pull File From Device – Specify a device from which to obtain a configuration and load it into the CMS.
