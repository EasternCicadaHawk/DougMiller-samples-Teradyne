Configure User Accounts and Authentication

Specify user settings for your configuration by clicking Site Configuration > Users & Authentication in the web UI tool bar to display the AAA screen, or by typing set aaa in the CLI. Refer to AAA (Authentication, Authorization, and Accounting) Overview for a general description of the CMS's user account management.

Follow these steps to configure a user account on the CMS:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do

Specify an existing user account to modify or begin defining a new user account.

Define the user's privileges and other information.

 Web UI: CMS > Users & Authentication to display the AAA screen. Click Authentication > Users to display the Users screen.

CLI: set aaa authentication users user username

set aaa authentication users user username [gid | homedir | password | ssh_keydir | uid]

REST API: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/aaa/authentication/users -d '{"user": {"name": "username", "uid": useridvalue, "gid": groupidvalue, "password": "passwordstring", "ssh_keydir": "/var/corero/homes/username/.ssh", "homedir": "/var/corero/homes/username"} }' --header "Content-Type:application/vnd.yang.data+json"

 Web UI: Click an existing user name, or click Add to begin defining a new user.

CLI: Specify the username to access its properties, whether you are modifying an existing user or creating a new one.

Specify values for username, UID, GID, Password, SSH Keydir, and Homedir. These parameters are described in the User screen topic.
Save your changes when you're finished. Web UI: Save CLI: commit REST API: Save/commit occurs automatically upon execution of the cURL command.

Return to the Basic Configuration Checklist if you're configuring your site for the first time.
