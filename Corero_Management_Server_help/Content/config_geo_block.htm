Block IP Addresses By Geography

It is possible to block IP addresses from one or more specific countries, or, otherwise, handle the packets originating from those countries in some special way. This combines elements of client group configuration with server protection instance configuration.

To block IP addresses based on their country of origin:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do
Define a geographic client group that includes the countries from which you want to block traffic. Web UI: Defense Configuration > Client Groups to display the Client Group screen.

CLI: set defense profiles client-group clientgroupname group-type geographic countries countryname

REST API: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/defense/profiles/client-groups -d '{"client-group": {"name": "clientgroupname", "group-type": "geographic", "countries": {"name": "countryname" } } }' --header "Content-Type:application/vnd.yang.data+json"

 Create a client group. Make sure it's a geographic client group that includes the countries you want to block.
Include that geographical client group in a server protection instance to block traffic from those countries to those servers. Web UI: Defense Configuration > Server Groups and Protection to display the Server Groups and Protection screen.

CLI: set defense server-protection server-group DEFAULT servergroupname service-protocol-group serviceprotocolgroupname client-group clientgroupname treatment action drop

REST API: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/defense/server-protection:server-protection/server-group/customername%2Cservergroupname/service-protocol-group/serviceprotocolname -d '{"client-group":{"name": "clientgroupname"}}' --header "Content-Type:application/vnd.yang.data+json"

Followed by:

curl -k -v -u admin:smartwall -X PATCH https://cmsipaddress/api/running/defense/server-protection:server-protection/server-group/customername%2Cservergroupname/service-protocol-group/serviceprotocolname/client-group/clientgroupname/treatment -d '{"treatment": {"action": "block", "admin-state": "enabled", "event-severity": "minimal", "security-ruleset": "All Rules Off", "reputation-ruleset": "All Reputation Rules Off", } }' --header "Content-Type:application/vnd.yang.data+json"

 Configure a server protection instance that uses the geographic client group. Make sure the treatment Action is configured to drop packets from the client group.
Save your changes when you're finished. Web UI: SaveCLI: commit REST API: Save/commit occurs automatically upon execution of the cURL command.

Return to the Basic Configuration Checklist if you're configuring your site for the first time.

The blocking of IP addresses by geography is closely related to the reputation data furnished by the Threat Update Service. Refer to the Threat Update screen description for information about configuring the Threat Update Service.
