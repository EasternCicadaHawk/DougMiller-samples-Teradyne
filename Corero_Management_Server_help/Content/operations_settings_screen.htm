Operations Settings screen

Click Defense Configuration > Operations Settings in the web UI tool bar to display the Operations Settings screen.

The Operations Settings screen provides these controls:

  • Global Defense Mode – Choose the operational mode for the shelf: Monitor, Mitigate, or Bypass.
  • Cluster – Specify the devices included in a high availability cluster.

These controls are available also through the CLI commands set defense operations-settings global-defense-mode and set defense operations-settings cluster.
