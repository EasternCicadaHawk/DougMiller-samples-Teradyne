Service Protocol Group screen

A service protocol group specifies the set of service protocols originating from a client group that will be handled with a particular treatment if encountered by the corresponding server group. Clicking Defense Configuration > Service Protocol Groups in the web UI tool bar displays the Service Protocol Group screen for defining collections of service protocols to be used in server protection instances. Alternatively, type the CLI command set defense profiles service-protocol-group to access the same functionality.

A number of service protocol groups are built-in and provided by default; these are basic groupings of commonly used protocols. You can define your own custom service protocol groups to collect service protocols for convenient use by your server protection instances.

Click Add in the Service Protocol Group screen to type a name for the group and create it. Choose one or more existing service protocols to include in the service protocol group.

Refer to Configuring Server Protection to see how service protocol groups are associated with server protection instances.
