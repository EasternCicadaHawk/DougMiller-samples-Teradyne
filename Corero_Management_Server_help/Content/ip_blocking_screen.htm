IP Blocking screen

Click Defense Configuration > IP Address Blocking in the web UI tool bar to display the IP Blocking screen for blocking one or more IP addresses completely. Alternatively, you can access this functionality by typing the CLI command set defense ip-blocking.

Blocking an IP address completely adds that IP address to a list of addresses that is consulted before any other part of the corresponding packet is examined. A packet from a blocked IP address is discarded immediately, and no additional processing is performed on any portion of its contents.

Refer to Block an IP Address Completely for instructions.
