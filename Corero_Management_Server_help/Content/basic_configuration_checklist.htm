Basic Configuration Checklist

Perform these procedures to define a typical basic configuration for your site. It may be that you don't need to configure every one of these features for your particular site, but this list comprises the basic, typical, recommended set of configuration tasks.

  1. Add an Appliance to the configuration.
  2. Obtain and install new software.
  3. Configure user accounts and authentication.
  4. Configure client profiles.
  5. Configure server protection instances.
  6. Block IP addresses by geography.

Make sure to save your configuration frequently throughout this process. At a minimum, you should save after completing each of these steps.
