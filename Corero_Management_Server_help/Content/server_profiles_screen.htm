Server Profiles screen

Clicking Manage Profiles in the Thresholds & Limits tab of the Server Groups and Protection screen displays the Server Profiles screen for defining sets of traffic characteristics that the appliance uses to identify traffic that is unacceptable to one or more servers. There are two separate profile types, each of which can be assigned to server groups independently. Each profile type is configured in its own screen, which is nested in this Server Profiles screen.

For each profile type, click Add to display the corresponding screen and begin creating a new one, or click the name of an existing profile to modify it.

All of these controls are available also through the corresponding CLI commands, as noted in each section below.

The Server Profiles screen provides these controls:

SYN Flood Profile

Specify a threshold value for the maximum number of connections. Three profiles are built-in: megaproxy-server-load, normal-server-load, and virtual-server-load.

You can access these controls also through the CLI command set defense profiles server-profiles syn-flood-profile.

Connection Limit Profile

Specify a maximum number of group connections (the default is 1048575) and a maximum number of member connections (the default is 32767). Four profiles are built-in: low-limits, normal-limits, very-high-limits, and virtual-server-limits.

You can access these controls also through the CLI command set defense profiles server-profiles connection-limit-profile.
