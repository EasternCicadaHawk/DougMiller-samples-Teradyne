System screen

Clicking CMS > System Info in the web UI tool bar displays the System screen, showing a summary of configuration information for your site:

  • Version – The version of Corero Management Server software that is running currently.
  • OVA Version – The version number of the virtual application software associated with the CMS software.
  • Config State – By default, this is Immediate, meaning that configuration changes are sent to the appliances directly and without delay when Save/commit is executed.
  • Last Defense Config Change – The time of the most recent saved change to the Defense appliance configuration.
  • Last Bypass Config Change – The time of the most recent saved change to the Bypass appliance configuration.
  • Last Forensics Config Change – The time of the most recent saved change to the Forensics appliance configuration.
  • Timezone – This pulldown enables you to specify a timezone for the CMS explicitly, rather than simply inheriting the timezone of the CMS host.
