Threat Awareness screen

Clicking Defense Monitoring > Threat Awareness in the web UI tool bar displays the Threat Awareness screen, providing controls for adjusting the broad, high-level behavior of the Defense appliance's DDoS identification functionality. When one or more of these thresholds is crossed, the Defense appliance uses functionality that is optimized to respond to massive amounts of incoming traffic.

The equivalent CLI command is:set defense threat-awareness [activation-thresholds | exit-thresholds]

The Threat Awareness controls are:

Activation Thresholds – These parameters specify thresholds above which the Defense appliance characterizes incoming traffic as constituting a DDoS attack.

  • New IP Addresses – The maximum number of new IP addresses allowed per second.
  • TCP Setup Rate – If a DDoS attack is not under way, already, this is the rate at which TCP traffic will be allowed to pass before reporting an interval as an attack.

Exit Thresholds – These parameters specify thresholds below which the Defense appliance determines that it is not encountering DDoS attack traffic.

  • New IP Addresses – The number of new IP addresses allowed per second.
  • TCP Setup Rate – The TCP Setup Rate exit threshold; this should be lower than the TCP Setup Rate activation threshold.
