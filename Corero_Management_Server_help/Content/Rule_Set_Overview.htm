Rule Set Overview

A rule set is a named collection of rules that is configured to identify and handle traffic for a particular purpose. For example, the appliance includes built-in rule sets with names like “Recommended Server Protection,” “Strict Server Protection,” "All Rules Block," and "All Rules Detect," each of which furnishes a collection of rules that have been enabled and configured to support the purpose for which the rule set is named. Every appliance comes with a number of these pre-defined rule sets built in. Every rule is included in every rule set; however, each rule can be enabled or disabled explicitly for a particular rule set, so that even though each rule is present in every rule set, it isn’t necessarily used. In addition, every other aspect of how an enabled rule is handled can be configured explicitly for a rule set; this includes the action to be taken when the rule is met, and any logging that is performed at that time.

There are two types of rule sets:

  • Security rule sets: Security rule sets describe behaviors for identifying and addressing traffic based on the nature of the traffic itself, such as its packet formation or its content.
  • Reputation rule sets: Reputation rule sets describe behaviors for identifying and addressing traffic based on the trustworthiness of its originating host.

Although the appliance contains default rules sets, you can modify those rule sets. Or, if you prefer, you can copy a rule set and use the copy to create a custom rule set to use in your server protection instances.
