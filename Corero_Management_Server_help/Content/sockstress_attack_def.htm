Sockstress Attack

Definition

Sockstress attacks are a type of attack that directs unusual traffic at a target's available TCP connections, with the intention of consuming them and preventing legitimate users from reaching them. Typically, these attacks complete the TCP three-way handshake, and exploit some subsequent aspect of TCP's behavior to tie up the connection.

The TCP zero window attack is a variety of Sockstress attack that ties up the corresponding TCP connection by setting the data window size to 0, causing the target to keep probing that connection to see if it's possible to place data there and use the connection.
