ICMP Flood Attack

Definition

An ICMP flood attack is a volumetric attack, a flood of ICMP requests intended to overwhelm the target's ability to respond. The ICMP flood is simply a barrage of ICMP messages (frequently, echo requests, or ping) sent at such volume and speed that the server is unable to keep up with the requests. In addition, since the ICMP messages expect a response, bandwidth is consumed on the way out, as well, as the server responds to each of the huge number of requests with a response of its own. The end result is that the server's bandwidth is fully consumed, leaving no room for legitimate traffic.

A Smurf attack is a variant of ICMP attack that uses the technique of amplification.

Observable characteristics

ICMP packets sent at a high rate.

Method of response

Drop all ICMP messages over a specified rate.

CMS configuration steps

None. ICMP packet rate limiting is enabled by default.

Relevant SmartWall rules

These rules pertain to this attack type:

  • cns-001022: Excessive non-TCP connection rate detected
  • cns-002007: ICMP packet rate exceeded threshold
  • cns-002008: ICMPv6 packet rate exceeded threshold
  • cns-003018: ICMP unsolicited echo response
