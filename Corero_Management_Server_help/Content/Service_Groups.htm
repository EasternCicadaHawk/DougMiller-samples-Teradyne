Protection Groups

A protection group is a collection of appliances that you configure to have the same security settings.

A protection group typically comprises appliances that share a common role or location at your site. The purpose of a protection group is to allow you to create and modify policies and environmental configuration items, and apply them as a group of settings to one or more appliances. You can also modify the settings within a protection group by automatically updating certain environmental configuration items using Threat Update Service Defense Packs.

A protection group is a collection of appliances that should have the same security settings. A protection group can contain one or more individual devices and/or one or more appliance clusters. Each protection group contains all of the settings required to make security decisions as the devices examine traffic flows. By collecting all of these settings into a protection group, you can easily manage the common settings you want to apply to specific sets of appliances.

A protection group enables you to specify the following types of settings across all protection group members:

• Firewall and intrusion protection policies, including shunning

• Rate-based policies

• Traffic rate limits

• Security environment configuration items, including:

• Address groups

• Services

• IPS rule sets (rules used by appliances to classify traffic as good or bad)

• IPS rule details (specific settings that apply to certain rules)

• IPS signatures (specific data patterns that identify problem traffic)
