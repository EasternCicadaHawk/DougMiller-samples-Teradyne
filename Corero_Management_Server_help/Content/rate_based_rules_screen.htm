Rate-Based Rules screen

Click Defense Configuration > Rate-Based Rules in the web UI tool bar to display the Rate-Based Rules screen, or use the CLI command set defense profiles rule-groups rate-limit-rules to access the same functionality.

This screen provides a catalog of all the rate-based rules used in the SmartWall Threat Defense System, displaying a summary of basic information for each, including its Admin State, Action, whether it is logged or not, its Severity, and short and long descriptions of the rule. Clicking a rule number displays a screen that enables you to customize the rule's configuration for that rule set: you can configure the treatment for a particular rule differently from one rule set to another, and you can modify the individual treatments, as well. Treatment modifications apply only to the instance of that rule associated with the named rule set.
