Network Storage screen

Clicking Site Configuration > Network Storage in the web UI tool bar displays the Network Storage screen for specifying storage resources used by Forensics appliances. Alternatively, type the CLI command set site packet-capture storage to access the same functionality.

The Network Storage screen provides these controls:

Storage section – Obtain the name of the target from your SAN.

  • Add – Click this to display the Storage screen for specifying the target of the packet capture data.
  • Delete – Select an existing target in the list and click this to remove it from the site.
  • Volume Name – The user-defined name of the target.
  • Device – Choose the Forensics appliance from which the target will receive packet capture data.
  • Type – Choose Iscsi or RAM.
  • Size – Specify the target size, expressed in GB.
  • Target – The formal name of the target, as obtained from your SAN.
  • Status – The current state of the target.
  • Admin State – Choose Enabled or Disabled to activate or de-activate the target.

Portal section – This is the IP address of the storage resource.

  • Add – Click this to display the Portal screen for specifying the name, IP address, and port of the storage resource.
  • Delete – Select an existing storage resource in the list and click this to remove it from the site.
  • Name – The user-defined name of the storage resource.
  • Host – The IP address or DNS name that identifies the storage resource.
  • Port – The port on which the Forensics appliance communicates with the storage resource. The default is 3260.
