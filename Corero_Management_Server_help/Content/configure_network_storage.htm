Configure Network Storage

If you are using a Forensics appliance to support packet capture activities, you must configure the network storage resource that will collect the packet capture data. This is done in the web UI by clicking Site Configuration > Network Storage in the web UI tool bar to display the Network Storage screen. Alternatively, type set site packet-capture storage in the CLI.

Configure the storage resource:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do
Add the portal. Web UI: Site Configuration > Network Storage to display the Network Storage screen. Click Add to display the Portal screen.

CLI: set site packet-capture portal portalname host ipaddress port portnumber

REST API: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/site/packet-capture -d '{"portal": {"name": "portalname", "host": "hostipaddress", "port": "portnumber" } }' --header "Content-Type:application/vnd.yang.data+json"

 Type a user-defined name for the storage entity and click Create. In the Host field, type the IP address or DNS hostname for the device. Type a port on which to communicate with it, or accept the default of 3260.
Add the storage volume. Web UI: Click Add in the Storage section of the Network Storage screen to display the Storage screen.

CLI: set site packet-capture storage volumename type iscsi size value device devicename target formaltargetname admin-state enabled

REST API: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/site/packet-capture/ -d '{"storage": ["volume-name": "volumename", "type": "iscsi", "size": value, "device": "forensicsappliancename", "target": "formaltargetname", "admin-state": "enabled" ] }' --header "Content-Type:application/vnd.yang.data+json"

 Type the volume name; this needs to be the formal volume name, as obtained via a system command. Then click Create to add the volume and begin configuring it. Specify the Device name; this is the Forensics appliance from which the network storage device receives data. Choose the Type of the storage device; this is Iscsi or RAM. Type the size of the device, expressed in GB. For Target, type the name of the PCAP file to which the data will be written. Specify an Admin state for the device, either Enabled or Disabled.
Save your changes when you're finished. Web UI: Save CLI: commit REST API: Save/commit occurs automatically upon execution of the cURL command.
