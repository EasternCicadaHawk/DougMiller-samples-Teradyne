Packet Capture screen

Click Defense Monitoring > Capture Admin & Queries from the web UI tool bar to display the Packet Capture screen. You can access the same functionality using the CLI command set forensics packet-capture.

The Packet Capture screen provides these controls:

  • Capture Mode – This indicates whether incoming packets are recorded (Capture) or not (Bypass); Bypass is the default. You can access the same functionality using the CLI command set forensics packet-capture administration capture-mode [bypass | capture].
  • Query Management – Display the Query Management screen for defining and administering capture queries. You can access the same functionality using the CLI command set forensics packet-capture query-management query queryname.
