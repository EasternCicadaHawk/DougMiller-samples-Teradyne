Configure Packet Capture Queries

Queries enable you to filter the set of packet capture data that is collected by the Forensics appliance. This is done in the web UI by clicking Defense Monitoring > Capture Admin & Queries to display the Capture Admin & Queries screen. Alternatively, type the set forensics packet-capture CLI command.

Define a packet capture query:

NOTE: If you use the CLI, remember to enter configuration mode prior to attempting any other configuration tasks. Do this by typing configure at the CLI command prompt.

Action Where to perform it What to do
Set the packet capture mode. Web UI: Defense Monitoring > Capture Admin & Queries to display the Capture Admin & Queries screen.

CLI: set forensics packet-capture administration capture-mode capture

REST API: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/forensics/packet-capture -d '{"capture:packet-capture": {"administration": {"capture-mode": "capture" }' --header "Content-Type:application/vnd.yang.data+json"

 Set the Capture mode to Capture. The default setting is Bypass.
Define a query. Web UI: Click Add to display the New Packet Capture Query dialog box.

CLI: set forensics packet-capture query-management query queryname

REST API: curl -k -v -u admin:smartwall -X POST https://cmsipaddress/api/running/forensics -d '{"capture:packet-capture": {query-management {"query": [ {"query-name": "queryname", "query-start-time": "time", "query-end-time": "time", "packet-length-min": "value", "packet-length-max": "value", "ip-protocol": "protocol", "flow-direction": "direction", "ethertype": "type", "query-batch-size": value } ] } } } ' --header "Content-Type:application/vnd.yang.data+json"

 Name the query. User-defined name.

Specify the start and end times of the query. query-start-time and query-end-time

Specify minimum and maximum packet lengths. packet-length-min, packet-length-max

Choose the IP protocol. ip-protocol

Choose the flow direction. flow-direction

Choose the Ethertype. ethertype

Specify the batch size.

Specify a range of source IP addresses.

Specify a range of destination IP addresses.

Specify a range of source port numbers.

Specify a range of destination port numbers.
Save your changes when you're finished. Web UI: Save CLI: commit REST API: Save/commit occurs automatically upon execution of the cURL command.

If the storage device associated with a Forensics appliance lacks sufficient space to collect a new query, the query fails and an alarm is generated. If this happens, delete some old queries to free space for the new query.
