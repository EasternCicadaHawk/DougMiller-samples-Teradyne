Early Access Capabilities screen

Clicking Defense Configuration > Early Access Capabilities in the web UI tool bar displays the Early Access Capabilities screen. This screen provides recently introduced threat defense commands that are made available on a provisional basis for evaluation in your configuration. Commands that prove over time to be used widely or frequently may be moved later to permanent homes with other related commands. Commands in this screen that do not prove to be used frequently over time may be deprecated in some future version.

Smart Rule Parameters – These parameters configure the Smart Rule feature, and specify thresholds and rate limits for protecting servers from flood attacks and reflection attacks. The CLI equivalent is set defense early-access-capabilities smart-rule-parameters.

  • Service Bit Threshold – The bit rate threshold over which a flood attack is determined to be occurring.
  • Service Bit Rate Limit – The maximum bit rate for traffic determined to constitute a probable flood against a service protocol.
  • Service Packet Threshold – The packet rate threshold over which a flood attack is determined to be occurring.
  • Service Packet Rate Limit – The maximum packet rate for traffic determined to constitute a probable flood against a service protocol.
  • Reflection Bit Threshold – The bit rate threshold over which a reflection attack is determined to be occurring.
  • Reflection Bit Rate Limit – The maximum bit rate for traffic determined to constitute a probable reflection attack.
  • Reflection Packet Threshold – The packet rate threshold over which a reflection attack is determined to be occurring.
  • Reflection Packet Rate Limit – The maximum packet rate for traffic determined to constitute a probable reflection attack.
  • UDP Server Bit Threshold – The bit rate threshold over which a UDP flood is determined to be occurring.
  • UDP Server Bit Rate Limit – The maximum bit rate for traffic determined to constitute a probable UDP flood attack.
  • UDP Server Packet Threshold – The packet rate threshold over which a UDP flood attack is determined to be occurring.
  • UDP Server Packet Rate Limit – The maximum packet rate for traffic determined to constitute a probable UDP flood attack.
