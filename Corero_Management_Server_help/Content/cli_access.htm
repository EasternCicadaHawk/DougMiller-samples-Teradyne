Accessing the CMS CLI

Access the CMS CLI from the CMS web UI by clicking CLI in the web UI tool bar, or access it directly using a terminal emulator (such as PuTTY) by initiating an SSH session to the CMS's management interface on port 2024.

The CMS provides a command line interface (CLI) that can be used for all configuration tasks, including:

  • Configuring all aspects of the CMS. Type configure at the CLI prompt to enter configuration mode.
  • Inspecting the configuration and state of Corero appliances.
  • Monitoring and inspecting log files.

The CLI is derived directly from the data models that describe the configuration of the objects managed by the CMS, and provides you with full access to those models for configuration and monitoring. The CLI supports these functions through two command modes: operational mode and configure mode.

The CLI provides a number of amenities for ease-of-use, including tab-completion of partial commands and full command line history.

Type ? at any time to display a list of commands available in the current mode, or type ? after a command name to display a brief help description for that command.

NOTE: The CLI requires use of the ASCII 0x34 double quotation mark (") symbol for both left and right quoting of strings when spaces or special characters are used in the input of a single field. Use of the left and right double quotation marks from the ISO and extended sets (8220 and 8221) is not supported, and will result in an error.
